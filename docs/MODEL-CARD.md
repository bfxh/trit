# 模型卡：部件平面头（trit-parts）

`publish = false` 的实验层模型，**不属于稳定 API**。所有数字都是本仓可复现命令跑出来的，
不是引用值；未验的条目在「局限」里逐条写死。

## 1. 它做什么

输入一帧 **384×384 RGB**（合成渲染的装配体），输出 **部件 id 图**：
`k=5` 条三进制平面（`3⁵ = 243` 个槽位，当前清单用 135 个）+ 1 条 `valid`（有无部件）。
id 由平面按 `id = 1 + Σ digitᵢ·3^(k−1−i)` 拼出，`0` 表示背景。

```text
RGB ──► 三值卷积网络 ──► 5 平面 logits + valid ──► 清单约束 argmax ──► id 图
```

判据口径：**id 一致率**（整像素 id 完全相同）与 **部件 IoU**，只在 GT 部件像素上统计
（背景占 ~96%，全像素口径会灌水）。

## 2. 结构

```text
x → e1 → pool → e2 → pool → e3 → u3 → cat(b) → d2 → u2 → cat(a) → d1 → head
```

- 13 层，通道 32 / 64 / 128（编码器-解码器 + 两处通道拼接的跳跃连接）；
- **权重是三值** `{−1, 0, +1}`（1.58 bit/权重）+ **每输出通道一个 scale**；
- 每层 **per-channel affine**（`y = relu(γ·v + β)`）——可学习 BN 的等价物，无 running stats；
- 反向只对「有效权重 `E = q·scale`」求导（GPU），`E → latent/scale` 的 STE 映射在主机侧，
  口径来自 `trit-learn::quant`（与 `trit-train` 同一套，不另立）。

导出包 `TPM1` 只含 `q / scale / γ / β / bias`，**467 KB**，约为训练断点（7.5 MB）的 1/16。

## 3. 训练配方（交付模型的来源）

| 项 | 值 |
|---|---|
| 数据 | 同一装配体的 12 个相机距离（2.0–4.2）× 150 帧，384²，合成渲染 |
| 优化器 | Adam，梯度累加 6，lr 3e-4 线性衰减到 1e-4 |
| STE | Identity |
| 样本数 | 约 35k（含一次从 1e-4 回退到 3e-4→1e-4 的续训） |
| 增强 | 光度抖动/噪声默认关（实测对域外无收益，见负结果） |
| 留出 | 距离 3.6 与 3.9（各 150 帧，共 300 帧，训练中未使用） |

## 4b. 深度预测：三版全否（3D 几何不来自本模型）

| 方案 | 留出深度 MAE | δ<1.25 | 分割 id | 结论 |
|---|---|---|---|---|
| 冻结骨干 + f32 线性读出 | 1.21 / 1.50 m | ~0 | 0.758 | 语义特征线性解码不出几何 |
| 共享 head 扩通道（三值平面） | 1.66 / 1.96 m | ~0 | 退化 | 分割被带崩 |
| **独立深度头（第 14 层，骨干冻结）** | **1.20 / 1.47 m** | **0.185 / 0.095** | **0.7907 / 0.7407** | 唯一不伤分割的方案，但精度差一个量级 |
| 独立头 + 最后 4 层解冻 | 1.06 / 1.23 m | 0.378 / 0.342 | 0.5995 / 0.5318 | 深度变好，分割塌 |
| 独立头 + 解冻 + 冻结分割 head | 1.21 / 1.30 m | 0.315 / 0.286 | 0.4738 / 0.4431 | 更差（特征漂了 head 补不回）|

- **监督口径不是杠杆**：4/5/6 平面 × 两个视差区间的 6 格扫描全落在 1.2–1.7 m（差异在 seed 噪声内）。
- **结论**：单帧 384²、无位姿/尺度输入时，深度与分割是**竞争关系**；深度到不了 3D 可用（≲0.1 m）。
  交付口径：**分割来自本模型，几何深度来自外部**（GT 或外部重建管线）。
- 用法：`parts-3d infer --model <tpm> --scene <dir> --frame N --manifest <parts.json> --out out.ply [--depth <npy>]`
  —— 模型出部件 id，深度由 `--depth` 或 `scene/depth/N.npy` 提供，输出逐部件着色的点云。

## 4c. 真实/域外图像：没有拒识（2026-10-31 实测）

用 4 张与训练装配体无关的图（1 张实拍餐食 + 3 张 AI 生成物），等比缩放到 384² 后跑 `parts-cli run`：

| 图 | 被判为部件的像素 | 不同 id 数 | 清单外 id |
|---|---|---|---|
| 实拍（生蚝餐盒） | **98.8%** | 121 | 0 |
| AI 生成（木环/微景观） | **97.0%** | 124 | 0 |
| AI 生成（枯木雕塑） | **98.6%** | 117 | 0 |
| AI 生成（苔藓机甲） | **95.8%** | 107 | 0 |
| 对照：域内 r3.6 第 0 帧 | **1.66%** | 117 | 0 |

- **模型没有拒识能力**：任何图像都会被打满部件标签（96–99%），不是"识别失败"，而是**全场幻觉**。
- 约束解码只保证"id 在清单内"，**不保证"画面里真有这个装配体"**。
- ⇒ 生产管线必须在模型**前面**加一道检测/定位门槛（或核对输入场景），不能把 valid 通道当"有没有物体"用。

## 4c. 真实图 / 域外：没有拒识能力（必须外挂闸门）

用 4 张与训练装配体无关的图（1 张实拍食物 + 3 张 AI 生成物，缩放到 384²）直接跑交付模型：

| 图 | 被判为部件的像素 | 不同 id 数 |
|---|---|---|
| 实拍食物 | **98.8%** | 121 |
| AI 生成物 ×3 | 97.0% / 98.6% / 95.8% | 124 / 117 / 107 |
| 域内（r3.6）对照 | **1.7%** | 94 |

⇒ **模型对「不是我的物体」没有任何拒识**：域外图上仍输出稠密的部件图。生产管线必须先判定
画面里是不是这个装配体（或加域外检测/先验），否则会得到看似正常、实际上全错的 id 图。

## 4d. 域外拒识闸门（阶段 1：手工特征 + 逻辑回归）

不改网络，用一次前向的产物算 15 个特征（部件像素占比、valid 均值/标准差/熵、id 邻域一致率、
5 条平面的 softmax 置信度、`d1` 特征幅值），再做二分类。伴生文件：
`crates/trit-parts/models/parts_id8118.ood`（533 B，SHA-256 `1437a722…70cb`）。

| 数据 | 读数 |
|---|---|
| 训练（域内 75 / 域外 ≈125 样本，域外=27 张负样本 ×翻/亮增强） | 训练集 AUC **1.000** |
| **留出（域内 200 帧 / 域外 29 张：生成图 + `baidu/MarathonDocBench` 文档页）** | **AUC 1.000，TPR@FPR≤1% = 1.000（域外 0/29 误收；域内最低 0.956 vs 域外最高 0.241）** |
| 你的 4 张实拍/AI 图（额外锚点） | 全部拒绝（最低分 0.0004） |
| 域内更远距离 r4.2（未训练） | 全部接受（得分 0.991+） |
| **困难取景**（相机钻进物体 / 贴脸近景，同物体但不可分割） | **AUC 0.80，TPR@FPR≤1% = 0**（全被接受）|

用法：

```bash
parts-ood check --model crates/trit-parts/models/parts_id8118.tpm   --manifest parts.json --bank crates/trit-parts/models/parts_id8118.ood   --image photo.png            # 域外时打印「拒绝」并以退出码 4 返回
```

⚠️ **边界**：这是「是不是这个物体类」的闸门，**不是**「这套取景能不能分割」的闸门——
相机钻进物体内部这类同物体错误取景仍会被接受（上表最后一行）。
另外负样本池目前 **54 张**（34 张生成图 + 20 张文档页，来自 `baidu/MarathonDocBench`），
另有你的 4 张实拍/AI 图（只做验收锚点）与 15 帧同管线困难取景（单独探针）。**注意边界在收窄**：
域内最低分 0.974→0.956、域外最高分 0.195→0.241，文档页是最难的一类负样本。重拟合用
`scripts/refit_ood.sh <model> <manifest> <pos-dirs> <neg-dir> [--apply]`（按文件名哈希确定性切分，
留出 **AUC≥0.99 且 TPR@1%FPR≥0.95** 才允许覆盖随仓闸门，否则退出码 1）。

## 5. 局限（必须读）

1. **只对训练过的装配摆放有效**。换一套部件坐标必须重训——零样本 id 0.0176（≈随机）。
2. **换装配时 id 必须沿结构顺序密集编号**。同一布局上把 id 随机置换后，8k 步的 id 从 0.196 掉到 0.088；
   按 z 序重编号可回到 0.130（+47%），但 A 仍是 1.5×——差距全在最低位平面，因为原布局的 id 是
   沿 z 的密集单序列（相邻差 1），而置换后的坐标只有 ~20 个不同 z 值（同层内只能任意破并列）。
   ⇒ 生产口径：**新装配按结构（父→子、沿装配轴）连续编号**，不要按名字哈希或随机打散。
3. **真实照片：已测，不可用**。4 张域外图被标成 96–99% 部件（见 §4c）；模型无拒识，必须在管线前加检测门槛。
   域外**合成**渲染（同装配、换外观）也没验过。
4. **分辨率固定 384²**，缩放到别的分辨率没有对拍过。
5. **速度**：单帧前向 16 ms（本机 wgpu）；批量 CLI 含解码约 35 ms/帧。没有做端到端帧率承诺。
6. **背景与遮挡**：`valid=0` 只覆盖背景；被完全遮挡的部件没有标签，模型对它们没有监督。

## 6. 部署

交付权重已随仓：**`crates/trit-parts/models/parts_id8118.tpm`**（479,208 B，SHA-256
`c83bb4e5997975cfe44df2fdc80492c431c69b4b341348e6485d48e33307c5b8`）。


一条命令（闸门 → id 图 → 可选点云；域外退出码 4）：

```bash
parts-cli pipeline --model models/parts_id8118.tpm --manifest parts.json   --bank models/parts_id8118.ood --image photo.png --out out/ [--depth d.npy --meta m.json]
```

```bash
# 训练断点 → 部署包
parts-cli export --state state.bin --out model.tpm

# 单帧
parts-cli run --model model.tpm --image rgb.png --manifest parts.json --out out/

# 批量（目录）
parts-cli batch --model model.tpm --dir rgb/ --manifest parts.json --out out/
```

库接口（给生成管线联动）：`api::infer_ids(backend, rgb, res, parts)`，后端为 `WgpuBackend` 或
参考实现 `RefCpu`；清单必须与训练时同一份装配清单，否则约束解码没有意义。

## 7. 复现

```bash
CARGO_TARGET_DIR=<大一点的盘> cargo build -p trit-parts --features gpu --release

# 对拍（需要夹具：见 README，夹具不在 git 里）
parts-parity ...
# 反向梯度检查（17 项）
parts-gradcheck
# 训练 / 续训
parts-train --data <距离目录...> --init <权重目录> --steps 35000 --lr 3e-4 --lr-final 1e-4 \
            --accum 6 --state <目录>
# 评估（两组指标并排）
parts-train --eval <留出目录> --manifest <parts.json> --resume <state.bin>
```

## 8. 负结果（别重复踩）

| 尝试 | 读数 | 结论 |
|---|---|---|
| 水平翻转 TTA | id 0.4455 | 翻转后的语义不成立，禁用 |
| 宽度 1.5×（net2net 加宽） | id 0.6698 | 加宽不提精度，反而更慢 |
| 块内残差 | 4k 步 0.0199；20k 步仍远差 | 残差与本结构不兼容 |
| 外观域随机化（光/色相/亮度） | 域内 0.6930、域外 0.336 | 不迁移，默认关 |
| 平移增强（`--augment-shift 8`） | loss 0.0055→0.752 | 边界 valid 带污染标签，默认关 |
| 跨布局零样本 | 0.0176 | 换摆放必须重训（见局限 1–2） |
| 两布局合训 | 原布局 0.7580→0.7196，新布局 0.0181 | 随机置换 id 下互相干扰 |
| 3 布局合训 15k | 训练布局 0.04–0.06（单布局 0.19） | 混训在同一预算下把 id 压 ~3× |
| Morton 序重编号 | 0.0633 | 二进制交织与 base-3 位不对应，比原样更差 |
| 深度：线性读出 / 共享 head / 头倍率 10× | 见 §4b | 共享 head 加 lr 会把分割打崩 |
| 深度：4/5/6 平面 × 2 区间 | 全 1.2–1.7 m | 量化口径不是杠杆 |
| 深度：解冻骨干 | δ 0.38 但 id 0.60 | 深度与分割竞争，不可兼得 |
| 3D：多视角并集 / 逐体素投票 / 持久性过滤 | 0.49 / 0.47 / 0.09 | 均不如单视角 0.60；1 cm 体素跨视角不重合，简单融合无效 |
