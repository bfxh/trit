# 01 语义规范：官方 YARA 4.5.4 到底怎么算

> 这份文件是**唯一真相**。每一条都来自官方引擎的实际输出（冻结在 `vectors/*.tsv`，共 2732 条）或 libyara v4.5.4 源码。
> 方括号里是向量 ID，例如 `[A007]` 指 `vectors/expr_core.tsv` 里 ID 为 A007 的那一行。
> 实现时遇到这里没写的情况：**不要猜**。先查向量文件有没有同类读数；没有就让它弃权（`Unknown` / `Unsupported`）。

记号：`U` 表示 `uint8(filesize)`，它在任何文件上都是 undefined（越界读）。

---

## 1. 两种“没有值”

| 名字 | 含义 | 例子 | 最终裁决 |
|---|---|---|---|
| `Undef` | 官方的 undefined：**确定**没有值 | 越界下标、越界读、零命中串的 `@a[1]`、运行期除零、非 PE 文件上的 pe 字段 | 不命中（False） |
| `Unknown` | 证据缺失：trit 自己的弃权 | 输入截断、命中表封顶、扫描预算耗尽、串不可扫描、缺 PE 上下文、字段没实现、循环预算耗尽 | Unknown |

两者一路分开传播，到规则裁决才合并：值非零 → True；值为 0 或 `Undef` → False；`Unknown` → Unknown。

**哨兵值**：整数结果恰好等于 `0xFFFABADAFABADAFF`（即 `-0x5452505452501`）时，官方把它当成 undefined [A100–A105]。实现里所有整数结果都经过 `xval::int()` 归一。

## 2. 运算符的三态传播

### 2.1 严格运算（表 1）

适用于：`+ - * \ %`、`& | ^ << >>`、`~`、一元 `-`、六个比较、字符串算子、`matches`、`intN()` 的参数、数组下标、字典键、函数实参、`$a at x` 的 `x`、区间端点。

|  | b 有值 | b = Undef | b = Unknown |
|---|---|---|---|
| **a 有值** | 按官方计算 | Undef | Unknown |
| **a = Undef** | Undef | Undef | Undef |
| **a = Unknown** | Unknown | Undef | Unknown |

- `Unknown` 碰上 `Undef` 得 `Undef`：不管未知的那一侧实际是什么，官方结果都是 undefined，所以这是确定的。
- 算术**没有短路**：`U * 0`、`U & 0` 都是 undefined [U011–U015]，所以 `Unknown * 0` 不能当 0。
- **唯一例外**：浮点的 `<`。任一侧 undefined 时结果是 0（有定义），其它五个浮点比较仍是 undefined [U070–U087]。

### 2.2 一元与裁决（表 2）

| x | 有值 n | Undef | Unknown |
|---|---|---|---|
| `not x` | n 为 0 得 1，否则得 0 | Undef | Unknown |
| `defined x` | 1 | 0 | Unknown |
| 规则裁决 | n 非零 True，n 为 0 False | False | Unknown |

读数：`not (U == 0)` 不命中 [U002]；`defined U` 不命中、`not defined U` 命中 [U024–U025]。

### 2.3 `and` 与 `or`（表 3）

先把操作数压成三值：非零为 T；0 或 `Undef` 为 F；`Unknown` 为 U。行是左操作数 a，列是右操作数 b。

| `a and b` | b = T | b = F | b = U |
|---|---|---|---|
| **a = T** | 1 | 0 | Unknown |
| **a = F** | 0 | 0 | 0 |
| **a = U** | Unknown | 0 | Unknown |

| `a or b` | b = T | b = F | b = U |
|---|---|---|---|
| **a = T** | a 的**原值** | a 的原值 | a 的原值 |
| **a = F** | 1 | 0 | Unknown |
| **a = U** | 1（a 是布尔型时）/ Unknown | Unknown | Unknown |

要点：

- `and`、`or` 的结果永远有定义。所以 `not (U == 0 or U == 1)` 命中、`not (U == 0 and true)` 命中 [U034–U058]。
- `or` 在左操作数为真时返回左操作数的**原值**，不是 1。这只在循环计数时看得出来：`for 2 i in (0..0) : (5 or false)` 命中，`(false or 5)` 不命中 [L056–L057]。
- “a 是布尔型”指 `Expr::is_boolean()` 为真（比较、字符串算子、`not`、`defined`、`and`、串引用、`of`、`for`、规则引用）。a 是整数型时原值不确定，所以给 `Unknown`。

### 2.4 布尔上下文

任何表达式都能当条件 [B001–B033]：

| 类型 | 为真的条件 | 读数 |
|---|---|---|
| 整数 | 非零 | `filesize` 命中，`0` 不命中，`-1` 命中 |
| 浮点 | **位模式**非零 | `1.5` 命中，`0.0` 不命中，`-0.0` 命中 [B011] |
| 字符串 | 非空（解析器在外面包一层 `StrToBool`） | `"abc"` 命中，`""` 不命中 |
| 裸正则 | 恒真 | `/a/` 命中 [B075] |

字符串进入布尔上下文的位置：规则条件的根、`and` / `or` / `not` / `defined` 的操作数、循环体。

## 3. 整数算术（运行期）

全部是 64 位有符号数。实现见 `sigscan/xval.rs::bin`（已按官方读数单测）。

| 运算 | 规则 | 读数 |
|---|---|---|
| `+ - *` | 回绕 | `9223372036854775807 + (filesize - 60) < 0` 命中 [A066] |
| `\` | 向零取整；除数为 0 或 `INT64_MIN \ -1` → Undef | `-5 \ 2 == -2` [A043]；`1 \ (filesize - filesize)` 是 undefined [A009–A010] |
| `%` | 结果取被除数的符号；除数为 0 或 `INT64_MIN % -1` → Undef | `-5 % 3 == -2`、`5 % -3 == 2` [A045–A046] |
| `<<` | 移位量 < 0 → Undef；≥ 64 → 0；否则按无符号左移 | `1 << 63 < 0`、`1 << 64 == 0` [A050–A051] |
| `>>` | 移位量 < 0 → Undef；≥ 64 → 0（负数也是 0）；否则算术右移 | `-8 >> 1 == -4`、`-1 >> 64 == 0` [A049, A054] |
| `~`、一元 `-` | 按位取反；回绕取负 | `~0 == -1` |

除法算子是 `\`。`/` 永远是正则的起始符，所以 `filesize / 2 > 1` 是语法错误 [A007]。

## 4. 浮点

- 字面量形如 `1.5`（小数点两边都要有数字）。`1.`、`.5`、`1e3`、`1.5KB` 都是错误 [A097–A099, F062–F063]。
- 整数与浮点混算时整数转成浮点。浮点只允许 `+ - * \`、一元 `-` 和六个比较；用在 `% & | ^ << >> ~`、`intN()` 参数、下标上是编译错误 [F030–F038]。
- `==` 是“差的绝对值 < `DBL_EPSILON`”，`!=` 是“≥”；其余四个是精确比较。所以 `0.1 + 0.2 == 0.3` 命中，同时 `0.1 + 0.2 > 0.3` 也命中 [F007–F008]。
- 浮点除以 0 不报错：`1.0 \ 0 > 1` 命中（无穷大）；`0.0 \ 0` 是 NaN，有定义，`==` 和 `!=` 都不成立 [F016–F023]。

## 5. 读数函数

`int8 int16 int32 uint8 uint16 uint32` 及各自的 `be` 变体，共 12 个。没有 64 位版本 [N042]。

- 参数是任意整数表达式。负偏移、越界 → Undef [N003–N006, N038–N041]。偏移**不**截成 32 位（与数组下标不同）。
- 有符号版本做符号扩展：`int8(255) == -1` [N009]。
- 输入截断时一律 `Unknown`（既有纪律，不动）。
- `filesize`：输入截断时 `Unknown`。
- `entrypoint`：调用方没传入口点时 `Unknown`（既有纪律）。官方在非可执行文件上是 undefined [N055–N057]，这三条是登记在案的弃权。

## 6. 字符串

### 6.1 字面量

转义只有六种：`\t \r \n \" \\ \xHH`（HH 恰好两位十六进制）。其它转义、字面量里的换行、未闭合，都是错误 [S111–S118]。字面量可以含任意非 ASCII 字节（按原样进入字节串）。空串字面量在条件里合法，在 `strings:` 段里是错误 [E004]。

### 6.2 比较与算子

实现见 `sigscan/xval.rs::ss_compare` 与 `sigscan/xstr.rs`（已回放 72 条官方读数）。

- 六个比较都支持，按**有符号字节**逐个比，前缀相同则短者小：`"\xff" < "a"` 命中，`"\x00" > "\xff"` 命中，`"a\x00" > "a"` 命中，`"abc" == "abc\x00"` 不命中 [S070–S097]。
- 算子 8 个：`contains icontains startswith istartswith endswith iendswith iequals matches`。
- 全部带长度、不在 NUL 处截断 [S103–S106]。
- 空针恒命中：`"abc" contains ""`、`"" contains ""`、`"abc" startswith ""` [S002–S003, S014]。
- 不区分大小写的版本只折叠 ASCII 的 A–Z：`"\xC4" icontains "\xE4"` 不命中，`"[" iequals "{"` 不命中 [S099–S100, S107–S109]。
- 操作数必须是字符串，否则编译错误 [S058–S069]。字符串不支持 `+ - * \` [B059–B062]。

### 6.3 `matches`

- 右边必须是正则字面量 [S061]。标志只有 `i`（忽略大小写）和 `s`（`.` 匹配换行），两个都有时顺序必须是 `is` [S044–S045]。
- 是**不锚定的搜索**：`"abc" matches /b/` 命中，`/^b/` 不命中 [S034–S035]。
- 没有 `s` 标志时 `.` 不匹配换行 [S040–S043]。
- 空正则 `//` 是错误（其实被当成了注释）[S053]。
- 正则引擎是现有的 Pike VM（`sigscan/regex.rs`，不改）。引擎不支持的语法：该 `matches` 结点求值为 `Unknown`。

## 7. 串相关的主表达式

记号：`$a` 在 `text` 样本里命中在偏移 0、20、39；`$b` 零命中。

| 表达式 | 语义 | 读数 |
|---|---|---|
| `$a` | 有命中为 1 | [M001] |
| `$a at x` | 任一命中恰在 x；x 为负数只是不命中 | `$a at 20` 命中 [M047]；`$a at -1` 不命中 [M054] |
| `$a in (lo..hi)` | 区间内有命中，两端都含；运行期 lo > hi 只是不命中 | [M058–M065] |
| `#a` | 命中次数 | `#a == 3` [M003] |
| `#a in (lo..hi)` | 区间内的命中次数 | `#a in (1..38) == 1` [M035] |
| `@a[i]` | 第 i 次命中的偏移，**i 从 1 起**；`@a` 等于 `@a[1]` | `@a[2] == 20` [M007] |
| `!a[i]` | 第 i 次命中的匹配长度；`!a` 等于 `!a[1]` | `!a == 2` [M024] |

undefined 的情形（全部**不是**编译错误）：

- `@a[0]`、`@a[-1]`、`@a[超过命中数]`、零命中串的 `@b` [M009–M016, M181–M185]。`!a` 同理。
- `x`、`lo`、`hi`、`i` 是 undefined 时，整个表达式 undefined [M051–M053, M066–M069]。
- `@a[i]` 的下标**不做类型检查**：`@a[1.5]`、`@a["x"]` 能编译，结果 undefined [M022–M023]。实现：浮点按位模式当整数，字符串直接给 Undef。

`$a at x` 的 x 必须是整数类型（`$a at 1.5` 是编译错误 [M055]）。

当整数用时：`#a` 为 3 所以真，`@a` 为 0 所以假，`!a` 为 2 所以真 [M004, M163, M032]。

### 7.1 不完整扫描（trit 自己的规则，官方没有这个概念）

“不完整”指：输入被截断、命中表封顶（65536）、扫描预算耗尽、串不可扫描。实现见 `sigscan/xfacts.rs`。

| 表达式 | 记录的命中能证明 | 证明不了，扫描完整 | 证明不了，扫描不完整 |
|---|---|---|---|
| `$a` | 1 | 0 | Unknown |
| `$a at x` | x 在命中表里得 1 | 0 | Unknown |
| `$a in (lo..hi)` | 区间内有命中得 1 | 0 | Unknown |
| `#a`、`#a in (…)` | 精确计数 | 精确计数 | Unknown；但 `#a <比较> 常数` 能由下界定出真假时照判 |
| `@a[i]` | 第 i 次命中的偏移 | Undef | i ≤ 0 时 Undef，否则 Unknown |
| `!a[i]` | 定长模式给静态长度，变长模式 Unknown | Undef | 同上 |

`scan` 层既有的两条折叠原样保留：含不可扫描串 → 整条规则 Unknown；不完整扫描下规则为 False → 折成 Unknown。

## 8. `of` 量词

形式：`<量词> of <集合>`，可选尾巴 `at x` 或 `in (lo..hi)`。

- 量词：`all`、`any`、`none`、整数表达式 N、百分比 `x%`。
- 集合：`them`、`($a, $b*, …)`。集合是**多重集**：`2 of ($a, $a)` 命中 [M084–M086]。`$a*` 匹配名字以 `a` 开头的所有串，`them` 等于 `($*)`。
- 设 found = 集合里成立的项数，count = 集合项数：

| 量词 | 结果 |
|---|---|
| `all`，或 N 在运行期是 undefined | found ≥ count |
| `none`，或 N 在运行期是 0 | found == 0 |
| N（非零） | found ≥ N（N 为负则恒真） |
| `x%` | `(found / count) * 100 >= x`（浮点）；x 是 undefined 则结果 undefined |

读数：`U of them` 命中（当作 all）[M103]；`(filesize - 61) of them` 即 0 of，`$a` 有命中所以不命中 [M105]；`(0 - filesize) of them` 命中 [M108]；运行期的 `0%` 恒真 [M101]。

- 尾巴的操作数是 undefined → 整个表达式 undefined [M118–M119, M124–M126]。
- 百分比不能带尾巴 [M290–M291]；尾巴不能连写 [M296–M297]。
- 规则集合：`any of (a*)`、`2 of (a1, a2)`。只用于规则名，不能带尾巴，不能用于 `for … of` [R018–R023]。

出现 `Unknown` 的项时（t / f / u = 成立 / 不成立 / 未知的项数）：实现见 `sigscan/xloop.rs::of_result`。

- all：f > 0 得 0；否则 u > 0 得 Unknown；否则得 1。
- none：t > 0 得 0；否则 u > 0 得 Unknown；否则得 1。
- N：t ≥ N 得 1；t + u < N 得 0；否则 Unknown。
- 量词本身 Unknown → Unknown。

## 9. 循环

形式：

```
for <量词> <变量> in <迭代源> : ( <体> )
for <量词> of <串集合> : ( <体> )
```

### 9.1 迭代源

| 迭代源 | 循环变量 | 备注 |
|---|---|---|
| `(lo..hi)` | 一个整数 | **两端都含** [L001–L004]；`lo == hi` 迭代一次 [L010] |
| `(e1, e2, …)` | 一个整数 | 元素可以是任意整数表达式，可以是 undefined（那一轮变量就是 undefined）[L093–L095]；单元素也行：`(filesize)` [L091] |
| `("a", "b")` | 一个字符串 | [L097–L099] |
| 数组，如 `pe.sections` | 一个对象 | `s.name` 这样取字段 |
| 字典，如 `pe.version_info` | 两个：键（字符串）、值 | 变量个数必须是 2 |
| 串集合（`for … of`） | 无；体内用 `$` `#` `@` `!` | 见 9.4 |

零次迭代的三种来源：运行期 lo > hi；任一端点是 undefined；被迭代的数组或字典是 undefined（非 PE 文件）。

### 9.2 官方算法

证据完整时**逐字**执行（实现见 `sigscan/xloop.rs::run_loop`，已单测）：

```
count = 0; iters = 0
对迭代器的每一项：
    body = 求值(循环体)              # 原值，可能是 undefined
    iters += 1
    继续 = 量词是 all（或 N 为 undefined）? body != 0
         : 量词是 none（或 N 为 0）     ? body != 1
         :                               count + body < N
    若 body 有值：count += body      # 累加原值，不是 0/1
    若不继续：跳出
结果 = iters == 0 ? 0
     : all  ? count == iters
     : none ? count == 0
     :        count >= N
```

body 是 undefined 时，上面的比较用哨兵位模式照算，三种量词都会继续。

由此得到的读数：

- 零次迭代：`all`、`any`、`none` **全是假**，而且是确定的假 [L013–L019]。
- 循环体是 undefined：`all` 假、`any` 假、`none` 真 [L029–L034]。
- 原值累加：`for 2 i in (0..0) : (5)` 命中；`for all i in (0..2) : (5)` 不命中；`for 3 i in (1..2) : (i)` 命中 [L038–L055]。
- 哪些表达式的值是 0/1：比较、`and`、`not`、`defined`、字符串当条件、`false or 5`。哪些带原值：整数表达式、浮点（位模式）、`5 or false` [L056–L070]。
- 运行期负数量词：只要迭代过一次就为真 [L079–L080]。

### 9.3 出现 `Unknown` 时

- 循环体出现 `Unknown`：改用三值计数，规则同第 8 节（t 是值为 1 的次数，f 是值为 0 或 Undef 的次数）。如果同时出现过 0、1 以外的原值，整个循环给 `Unknown`。
- 量词、端点、被迭代对象是 `Unknown`：循环给 `Unknown`；能证明零次迭代时仍然给 0。
- 预算：每条规则的循环体求值总次数上限 `EVAL_BUDGET`（2^22），耗尽给 `Unknown`。

### 9.4 `for … of`

- 迭代集合里的**每一条**串，包括零命中的 [M206, M207, M235, M237]。
- 体内：`$` 当前串有命中；`$ at x`；`$ in (…)`；`#` 命中次数；`@` / `@[i]`；`!` / `![i]`。
- 这四个符号在 `for … of` 之外使用是编译错误 [M154–M160]。
- `for … of` 不能套在另一个 `for … of` 里；与 `for … in` 互相嵌套没问题 [M153, M145, M146]。

### 9.5 作用域

- 循环变量只在自己的体内可见；出了体使用是“未定义标识符” [L122–L123, L126]。
- 内层变量不能与任何外层变量重名 [L118–L119]。
- 最多嵌套 4 层（两种 `for` 都算）[L120–L121]。
- 循环变量遮蔽同名的模块：`for any pe in (0..1) : (pe == 1)` 命中，体内 `pe.is_pe` 是错误 [L148–L149]。
- 整数或字符串型的循环变量后面不能跟 `.` `[` `(` [L150–L152]。
- 对象型的循环变量不能直接当值：`for any s in pe.sections : (s == 1)` 是错误 [I149–I150]。

## 10. 模块对象

### 10.1 取值

- 数组下标先截成 **32 位有符号数**再取元素：`pe.sections[4294967296]` 等于 `pe.sections[0]` [I007–I011]。负数或越界 → Undef。
- 字典键区分大小写；查不到 → Undef [I019–I022]。键在第一个 NUL 处截断。
- 函数：任一实参是 undefined → 结果 undefined。
- 模块常量（`pe.MACHINE_AMD64` 等）与文件无关，任何文件上都有定义 [I189]。

### 10.2 非 PE 文件

`pe.is_pe` 是 0（有定义）；常量有定义；**其余字段和函数全是 undefined** [I183–I223]。所以 `not (pe.number_of_sections == 0)` 不命中，`not for any s in pe.sections : (true)` 命中。

### 10.3 证据状态（trit 自己的规则）

| 入口 | `pe.*` 的结果 |
|---|---|
| `scan`、`scan_with_entrypoint`、`scan_with_context(.., None)` | Unknown（常量除外） |
| `scan_with_context(.., Some(info))`，输入未截断 | 官方口径 |
| `scan_file`（CLI 用） | 官方口径；非 PE 时如 10.2 |
| 任何入口，输入截断 | Unknown |

pe 字段的具体取值规则见 `03-PE-MODEL.md`。

## 11. 规则级

- **规则引用**：标识符是前面已定义的规则名时，值是该规则是否命中（1 / 0，永远有定义）[R010–R015]。引用后面的规则是编译错误 [R016]。引用自身合法，值是 0 [R017]。规则引用是布尔类型，不能参与算术或比较 [R011–R012]。
- **`private rule`**：照常求值，可以被引用，不出现在结果里 [R001–R002]。
- **`global rule`**：任一 global 规则不命中（含 undefined），整个文件没有任何命中，写在前面还是后面都一样 [R003–R009]。
- **`import`**：用模块之前必须先 `import`，且 `import` 要写在使用它的规则之前 [R025–R027]。未知模块名是错误 [R029]。
- 未实现的模块（`math`、`hash` 等）：`import` 之后可用，值一律 `Unknown`。

出现 `Unknown` 时：被引用的规则是 Unknown 或 Unsupported → 引用处是 `Unknown`；global 规则是 Unknown → 其它规则的 True 降成 Unknown，False 不变。实现见 `sigscan/xscan.rs`。

## 12. 向量文件怎么读

| 文件 | 行数 | 列 |
|---|---|---|
| `vectors/expr_core.tsv` | 1408 | `id  fixture  strings  cond  official` |
| `vectors/pe_fields.tsv` | 1252 | 同上 |
| `vectors/rule_level.tsv` | 72 | `id  fixture  source  official` |

- `official`：`HIT` / `MISS` / `ERR`（官方编译错误）/ `CRASH`（官方编译器崩溃，按 ERR 对待）；规则级文件是 `HITS:<逗号分隔的规则名>` 或 `ERR`。
- `strings` 为 `-` 表示没有 strings 段；多条串用两个空格隔开。
- 字段里 `\u{HH}` 表示一个原始字节（0x20–0x7E 之外的字节都这样写）。
- 单条件向量的规则源固定是：

```
import "pe"
rule v {
 strings:
  <strings>
 condition:
  <cond>
}
```

- 样本在 `fixtures/<名字>.hex`，每行 32 字节的十六进制。`text` 是 61 字节的文本，`bytes256` 是 0x00–0xFF，其余是合成的 PE。
- ID 首字母是主题：A 算术、B 布尔上下文、U undefined 传播、L 循环、S 字符串、N 读数函数、F 浮点、M 串主表达式与 `of`、I 下标与对象、E 串声明、P/Q pe 字段、R 规则级。
