# trit-wspace 未证栏（汇总）

把各结果文档的“未证栏”集中到一处，避免只写在单个文件末尾。每条给来源与补证所需。

## 1. 真实模型 / 任务指标

| 项 | 现状 | 补证 |
|---|---|---|
| f32 bias 的端到端收益 | 已补真实激活（`real_activations` + `bias_e2e --activations`）：第 0 段 query 的真实输入下 rel_l2 为 zero 0.6531 / trit 0.6044 / f32 0.4526，与随机输入的方向不一致（见 WSP-SUMMARY §12）；中间/输出段仍是随机输入 | 跑完整 6 层真实激活；在检索/分类任务上测 |
| WSP4 的更大模型 | 只在 all-MiniLM-L6-v2（103 张量，5,985,699 B）上测；82.7% of WSP2 | 更大模型/GPU；不同稀疏度 |
| DARE 块级重标度 | `dare` 已实现坐标/行/层/块丢弃与报告；块级重标度细节未证 | 在真实任务向量上对拍 |
| 学习式提议器 | 4→8→1 随机网络 + 采样 oracle；单工件内留出编辑 | 跨任务/跨工件留出；真实任务 oracle |
| 真实任务精度 | 已补 STS 全量读数：baseline 0.8204、分组三值 0.8200（15.06×）；6 层全量真实 tuned 在 STS test 上是**负结果**（edit −18.0 点 / keep −14.2 点，§13）；**推理式编辑用 1 个 trit 拿到与 1505 个 trit 梯度微调相同的任务收益**（§14） | 多 seed / lr 扫描；6 层三值网络上的推理式编辑；tuned 权重三值化后的任务指标 |

## 2. 容器 / 互操作

| 项 | 现状 | 补证 |
|---|---|---|
| GGUF ↔ llama.cpp | `TYPE_TRIT=100` 是自定义类型，上游不认；张量名未映射 `blk.N.*` | 在 llama.cpp 侧加类型或转换器；实测加载 |
| GGUF 不保留 f32 bias 幅度 | 103 张量往返 67/103 逐字节一致；36 个带 `biasf` 的 `.weight` 只差 biasf/checksum | 扩展 TYPE_TRIT 数据段或旁车文件 |
| WSP3/WSP4 随机访问 | 两者是整段压缩流，不能按块随机读 | 分块压缩（每块独立码表），接受压缩率损失 |
| WSP2 索引 | 固定 64 行块；未接 mmap；默认只查长度 + 尾部校验和 | 自适应块；mmap；读时全量校验 |
| WSP2G（分组二进制） | 组号段已按 `ceil(log2 组数)` 位打包，但只有整层解码；`BlockIndex` 只认 v1/v2 | 行块偏移扩到组号段（元素区间 → 位区间），再出随机读 |
