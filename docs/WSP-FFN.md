# 两层 FFN 上的编辑集门禁

## 为什么从单层换成两层

`editset_sts` 的学生只有单层 `query`（384→384），准确率 55%–93% 已经把表达力上限摆在明面上。
WSP1 本来就支持多层（`Net::new` 接受多层、`arch` 输出多维），所以**不用改格式**——直接把学生
换成 MiniLM 里的真实两层 FFN：

| 张量 | 形状 |
|---|---|
| `encoder.layer.0.intermediate.dense.weight` | 1536×384 |
| `encoder.layer.0.output.dense.weight` | 384×1536 |

384 → 1536 → 384，无 attention。WSP1 的 `Layer` 只有符号激活，没有 GELU / LayerNorm / 残差。

## 训练

`scripts/train_ffn.py`：协议级微调两层，前向用 STE 三值化：

```python
ste_sign(x @ ternarize(W1).T) @ ternarize(W2).T
# 目标：BCE(cos(y_a, y_b) × 4, label)
```

3 个 seed（7,13,29），valid 准确率 **0.8576 / 0.8739 / 0.8680**（base 0.7107 / 0.7240 / 0.7463）。

## 读数（872 对，3 seed × 3 阈值）

| threshold | 基线 对/错 | edit_fixed 均值（范围，sd） | keep_broken 均值（范围，sd） | 补丁后正确 均值 |
|---|---:|---|---|---|
| 0.3 | 755 / 117 | 0 | **41.0**（29–47，sd 8.49） | 714.0（708–726） |
| 0.5 | 569 / 303 | **127.0**（117–133，sd 7.12） | 0 | 696.0（686–702） |
| 0.8 | 534 / 338 | 4.33（2–8，sd 2.62） | 0 | 538.33（536–542） |

`delta` 三值变化均值 **396,842**（layer 0 约 174k + layer 1 约 223k）。

## 与单层的对照：阈值迁移

| threshold | 单层 `query`（5 seed） | 两层 FFN（3 seed） |
|---|---|---|
| 0.3 | 修 51 / 破坏 0 | 修 0 / 破坏 41 |
| 0.5 | 修 0 / 破坏 31 | **修 127 / 破坏 0** |
| 0.8 | 修 0.4 / 破坏 0.4 | 修 4.3 / 破坏 0 |

读法：

1. **两层把“有利区间”从 0.3 推到 0.5**：0.5 阈值下修 127、破坏 0（单层是修 0、破坏 31）；
2. 但两层在 0.3 阈值下破坏 41（单层是 0）——**表达力更强 ≠ 全阈值更好**，阈值必须跟着网络容量调；
3. 0.8 阈值下两层修 4.3（单层 0.4），高阈值区间也略好。

## 未证栏

- WSP1 的 `Layer` 只有符号激活，没有 GELU / LayerNorm / 残差——这是与真实 FFN 的差距；
- 训练是协议级（句向量 → 两层三值前向），不是 HF 端到端微调；
- 3 seed、872 对；`changed` 约 39.7 万 trits，是单层合成 Δ 的 39 倍；
- 只用了 `layer 0` 的两层 FFN，没有堆叠更多层；
- 阈值与网络容量的关系（阈值迁移）只在两个网络规模上观察过。

## 接口

- `examples/editset_ffn.rs`：两层 FFN 门禁，输出与 `editset_sts` 相同的 `certificate`；
- `scripts/train_ffn.py`：协议级微调两层 FFN（STE 三值化）。
