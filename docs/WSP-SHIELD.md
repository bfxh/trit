# 防御沙盘三件套：预测 / DDoS 盾 / 身份锁定（2026-11-14）

接 #492-#495 的三值 QAT 线与红队线，补**防御面**与**预测组件**，并按用户
要求做「预测 / 学习 / 进化」三组件的组合消融。两条硬边界先立此存照：

1. **不做对真人的定位/去匿名化**。「追踪攻击者」落在防御遥测的
   campaign/僵尸家族**聚类标签**上（哪个攻击活动、多大规模），不落到
   具体个人或物理位置——那需要网络层取证与法律程序。
2. **不做攻击反制**。「破解 DDoS」按**瓦解攻击**（ Absorb/过滤/预算）实现，
   不回打。P=NP 澄清：不存在"OpenAI 无限接近 P=NP"的论文；P vs NP 是
   未解问题。本仓做的是启发式搜索的**工程极限实验**，不是复杂度突破。

## 1. 预测组件（`trit_learn::forecast`，可发布层）

`SMA`（滚动平均）/ `Ewma`（在线 EWMA）/ `Holt`（水平+趋势，O(1) 流式）
与 `mae`/`rmse`/`mape`。4 条单元测试（窗口前缀、阶跃跟踪、线性趋势外推、
指标零点/跳过零真值）。服务 DDoS 盾的自适应预算。

## 2. DDoS 盾（`examples/ddos_shield/`）——三组件消融沙盘

全部流量本仓合成（零网络 I/O）。三个僵尸 campaign（高速洪水 / 慢速重试 /
僵尸轮换）随时间**变异**，正常流量带日周期。三档防御消融（248 窗口，
正常 200 / 攻击 48）：

| 防御 | 拦截攻击 | 误杀正常（透明性） |
|---|---:|---:|
| 静态阈值 6.0 | 44/48 | **0** |
| 静态 + Holt 预测自适应预算 | 27/48 | **0** |
| + QAT 学习分类器 | 6/48 | 10（0.05） |

**判读（消融矩阵的价值就在不迷信组合）**：
- 静态阈值对**已知**高强度模式最有效（零误杀）；
- 预测自适应的收益在**防阈值探测**与应对流量基线漂移（本合成序列基线
  平稳，收益未显现——如实记录）；
- 学习组件 v1 特征/训练量不足（攻击拦截 6 + 误杀 10），冷启动期与训练
  预算是主因——列为后续，不掩盖。
- **campaign 归因**：被拦窗口的源指纹哈希单链聚类 → campaign 标签 +
  规模（防重复投毒的遥测底座）。

## 3. 身份锁定（`examples/identity_lock/`）——校验和盲区的补位

行为指纹 = 50 个固定探针上的输出符号向量（发布时锚定）。三个部署实例：

| 实例 | 指纹漂移 | 锁定 | 后门探针命中 |
|---|---:|---|---:|
| 忠实副本 | 0.0000 | 否 | 0 |
| **真后门**（输出层 30% trits 反转，字节合法+校验和重算） | 0.1600 | **是** | 2 |
| 幻觉副本（30% 行随机扰动） | 0.1600 | **是** | 2 |

- **忠实副本零误杀**；两类偷换（后门/幻觉）全被**行为级指纹**锁定——
  这正是 #495 方向修正的实证：字节完整性归校验和，**行为完整性归探针
  指纹**，两者互补不冗余；
- 「哑弹投毒」（打在不承重行上，行为等价）不触发锁定——**语义上正确**：
  防御只对行为变化负责；
- 锁定后动作：从基线回滚（逐位一致验证 ✓）+ 审计记录（`AuditLog` 同款
  哈希链，接 #495）。

## 5. 未证栏

- 流量全合成：真实 PCAP/CDN 日志上的泛化未证；
- 学习分类器 v1 弱（特征 64 维 one-hot、冷启动 60 窗、训练量小）——
  消融矩阵如实暴露，改进方向是流式增量训练与更多特征；
- 行为指纹的探针集是固定的——自适应探针（对抗探针枚举）未做；
- DDoS 的真实协议栈（SYN/应用层）未建模，只有聚合窗口。
