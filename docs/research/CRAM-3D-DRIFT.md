# CRAM + 3D 漂移：S 级任务包

> 状态：**设计，未开工**。起点 `main` @ `e33b92ad`。
> 外部背景（已核实）：CRAM = [arXiv:2611.17309](https://arxiv.org/abs/2611.17309)
> （Hoover 等，2026-11-12），Hopfield & Tank 能量的学习版，Sudoku-Extreme 99.996%、
> Maze-Unique 100%，单卡训练 42/132 ms。漂移模型（1-NFE）**未指定具体论文**，
> 本包用「吸引/排斥力场的一步生成器」泛指。

## 0. 一句话

把 CRAM 的能量函数当成 3D 生成漂移模型的「物理裁判」：用能量否决穿模/断裂的中间状态，
用旋转不变能量省掉对称化，用能量引导的摩擦力稳定训练。先做 **2D 最小切片**，不直接上 3D。

## 0.5 现有资产（不要从零写生成器）

`/d/KF/driftnet` 已经有 Rust 三值 **1-NFE 生成器**与训练：

- `crates/driftnet`：推理（三值量化、2-bit 打包、`trit-ops` 双导轨 GEMV、WGSL GPU 核）；
- `crates/qat`：训练（STE + patch SWD + hinge，默认 `trit-grad` 后端）；
- `crates/trit-grad`：三值专用反向引擎；
- 当前任务是 CIFAR-10 32×32，训练/推理全 Rust，复用 `trit@fe93a76`。

因此 M0b **不是「写生成器」**，而是改 driftnet 的输出头/数据与 loss：把 3×32×32 换成
2D 轨迹点集（或 3D 点云），在 `crates/qat` 的 loss 里加 CRAM 能量项；推理侧可做
「生成 N 个 + 能量选最小」的事后筛选。

## 1. 问题与假设

1-NFE 漂移模型在 3D 生成上的三个痛点：旋转对称性、模式崩溃/物理不可行、训练不稳定。
本包只验证三条可机器判的假设：

| 编号 | 假设 | 判据 |
|---|---|---|
| H1 | 能量否决提高物理可行率 | 比无能量基线 **≥10 个百分点** |
| H2 | 旋转不变能量减少对称化成本 | 固定 seed 下训练步数或 wall-clock **下降** |
| H3 | 能量引导的摩擦力稳定训练 | 固定 seed 下 loss 曲线无爆炸（不出现 inf/NaN） |

## 2. 最小切片（M0：2D，不碰 3D）

- **数据**：2D 障碍物轨迹（自生成，8×8 网格起终点，BFS 可穷举）；小分子 2D 构象（公开数据，M1 再用）。
- **生成器**：1-NFE 漂移模型（D 维点集，吸引/排斥核），CPU 可跑。
- **能量**：CRAM 风格 Hopfield 能量 + 三个约束项（不穿模、不断裂、旋转不变）。
- **三组对照**：
  - A：无能量（基线）
  - B：事后筛选（生成 N 个，能量选最小）
  - C：训练时能量惩罚
- **指标**：物理可行率、模式覆盖率（唯一轨迹/模式数）、与真实轨迹的 Chamfer/Hausdorff 距离、
  训练/推理时间。

## 3. 验收（机器可判）

- **独立 oracle**：2D 网格最短路径用 BFS 穷举，逐点 `DIFF=0`；能量对旋转 ±90° 的读数
  逐位相同（性质测试）。
- **性质测试**：旋转不变性、平移不变性、固定步长下能量单调下降。
- **性能预算**：M0 单核 CPU ≤5 分钟跑完 3 组 × 3 seed；GPU 非强制。
- **负结果入册**：H1/H2/H3 任一不成立，写进 `docs/research/CRAM-3D-DRIFT-RESULTS.md`。
- **门槛**：H1 的物理可行率提升 ≥10 个百分点，且 B/C 至少一组覆盖率不劣于 A。

## 4. 交付物

- 本文件（设计）。
- `docs/research/CRAM-3D-DRIFT-RESULTS.md`（读数 + 未证栏）。
- `benchmarks/cram-drift-2d/`（独立 workspace，不进 CI）：Rust 实现 + 仅用于对齐的 Python 基线。
- 数据生成脚本（固定 seed，可复现）。

## 5. 禁区

- 不做 3D 生成（NeRF / Gaussian / mesh），直到 M0 的 H1 成立。
- 不用外部预训练模型顶替生成器。
- 不把 Python 训练产物当交付（Python 只作对齐基线）。
- 不在没有独立 oracle 的情况下宣称「物理可行」。

## 6. 失败回退

- M0 任一组不达门槛：停止，写负结果，不进入 3D。
- 能量设计做不出旋转不变：退回「事后筛选」基线，记录差距。

## 7. 里程碑

| 阶段 | 内容 | 验收 |
|---|---|---|
| M0a | 2D 轨迹数据 + BFS oracle | 穷举 `DIFF=0` |
| M0b | 复用 driftnet 的 Gen/qat，换 2D 轨迹输出 + 能量项 | CIFAR 原读数不退化；2D 轨迹的 BFS oracle DIFF=0 |
| M0c | CRAM 能量 + 三组对照 | H1/H2/H3 读数 |
| M0d | 创造力机制：过程/产品解耦（primer 分层 + 掩码解码），见 [`CRAM-3D-DRIFT-CREATIVE.md`](CRAM-3D-DRIFT-CREATIVE.md) | E1 掩码解码可行率 ≥90%；E2 primer 新颖度 +20% |
| M1 | 小分子 2D 构象 | 同一套指标 |
| M2 | 3D 扩展（仅当 M0 通过） | 另行设计 |

## 8. 难度与工作量

- 难度：**S**（独立 oracle / 性质测试 / 性能预算 / 负结果入册四门槛齐全）。
- 预估：M0 2–3 周（单人），M1 +1 周，M2 另计。
- 与 trit 主线的关系：**弱**（连续能量 vs 三值离散）；借的是「能量下降 + 早停 + 可解释」。
