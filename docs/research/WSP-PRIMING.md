# 三值创造性预激发：悖论假设的实验检验——本配置下不显著（2026-11-20）

把 Albalak「创造性悖论」（模仿过去成功会扼杀未来创造性）与其解法「创造性
预激发」（解耦过程与产品：冻结执行器，只训练预激发器）落到三进制红蓝对抗
上。**诚实结论先行：在本配置下悖论不显著**——但根因分析给出了可检验的
边界条件，并暴露了预激发奖励的代价曲线。

## 1. 映射（`examples/creative_priming/`）

| 论文概念 | 三进制实现 |
|---|---|
| π_resp（冻结响应模型） | **冻结攻击执行器**：`Edit::SetTrit` 原语 + #492 工件（动词表固定：+1 行置零 / -1 行取反 / 0 不动，不可训练） |
| π_CP（预激发模型） | **行-动作偏置表**（REINFORCE 查表近似，v1；QAT 生成器列后续） |
| Y_CP（primer） | 长度 129 的三值行优先级基因组（同 #497） |
| 奖励（悖论组） | 攻击质量（spam F1 打击量）——**复制过去成功的悖论触发条件** |
| 奖励（预激发组） | 质量 × 新颖度（与历史 primer 的最小汉明距离）——**明确奖励不复制** |
| RL 组大小 G | 8/16/32/64 sweep，4 代偏置更新 |

诚实声明：v1 的 π_CP 是查表偏置近似，不是 QAT 生成器；4 代偏置更新远短于
论文的 RL 训练量。**负结果在该配置下成立，外推需谨慎**。

## 3. 判读（三条，都有反直觉价值）

1. **悖论在本配置不显著，且方向相反**：悖论组多样性随 G 微升（0.568→0.582）
   而非塌缩。根因：执行动词表里 25% 的硬探索 jitter **不受奖励驱动**——
   足够的探索噪声本身就是抗悖论机制。论文的 RL 无此噪声，故塌缩。
   **推论**：进化类攻击器（#497）天然带探索噪声，比 RL 攻击器更抗悖论——
   这对红方工具设计是好消息，也预示「纯奖励 RL 攻击器」反而是弱攻击形态。
2. **预激发奖励的代价曲线**（论文未给的读数）：G=8 时新颖度×质量乘积把
   F1 稀释到 0.538（-27%）——小种群下多样性奖励直接吃掉攻击强度；G≥16
   恢复。**预激发不是免费的**：新颖度项的权重需要随种群规模调节。
3. **F1 上限 0.7353 恒定**：执行动词表（置零/取反）在不触输出层 kill-switch
   的前提下，行级攻击的 F1 打击上限由 #494 的结构决定——primer 的多样性
   改变攻击的**覆盖面**（抗防御迁移），不改变单次上限。

## 4. 对 #495 负结果的悖论解释（修正记录）

#495 完整性审计模型 acc 0.11 的根因现在有更准确的名字：**创造性悖论的
防御侧表现**——用过去攻击样本训练检测器，检测器只会复制已知攻击模式
（中位数陷阱）。修正路线照论文映射：冻结检测器主体，训练**探针生成器**
（π_CP 角色：生成让检测器不确定的输入），奖励 = 检测覆盖的多样性×质量。
`artifact_guard` 的攻击样本生成器已是这个角色的雏形，方向确认。
