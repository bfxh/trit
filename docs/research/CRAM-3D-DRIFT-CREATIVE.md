## 0. 一句话

漂移模型缺的不是容量也不是条件通路（条件已经能被用起来，换 goal 改输出 83%），
缺的是**把「过程」从「产品」里拆出来**：让一个小 primer 模型负责「往哪走」，
让生成器/解码器负责「画成什么样」，奖励只回流到 primer。

## 2. 三个可落地机制

### P1（主推）两层生成：primer → 漂移生成器

现在的形态是 `fc([z(128), goal_onehot(64)])` 一步出 32×32。改成：

```text
ε ~ N(0, I)  ──┐
goal ──────────┴→ primer P(·) → π ∈ R^d (d = 16)
                                │
z ~ N(0, I) ──┐                 │
goal ─────────┼→ 生成器 fc([z, goal_onehot, π]) → 32×32
```

- `π` 是「过程码」：起步方向、转弯偏好、路径密度这类**策略**量，不含具体像素；
- `cond` 从 64 扩成 `64 + d`（现有 `--cond` 通路直接复用，`fc` 宽度 192 → 208，成本可忽略）；
- 训练分两步：
  - **A（冻结生成器）**：对每个 goal 采 K 个 `π`，每个 `π` 配 G 个随机 `z` 生成图片，
    奖励 `R = w_f·可行(能量=0) + w_n·新颖(到训练集最近邻距离) + w_d·多样(组内两两距离)`，
    **组内标准化成优势**后用 REINFORCE/GRPO 更新 primer。生成器不更新。
  - **B（可选）**：把 `π` 当条件重训生成器（或只训一个极小适配器，见 P3），让它学会「按 π 渲染」。

为什么这样能绕开九条负结果的坑：负结果全部是「同一个网络 + 同一个损失里加约束」——
约束梯度被 SWD 淹没、且强化了特定产物（竖线）。P1 把奖励挪到**过程**上，产物侧只被
「条件」影响，不被奖励直接拉扯，因此不会塌缩到单一形态。

### P2 掩码解码：连通性从 loss 挪到解码器

R1 的「过程/产品」解耦，在离散结构上最干净的实现是**掩码解码**（R4 的做法）：

- 8×8 二值网格按 BFS 顺序逐格决定是否点亮；
- 每一步的掩码只允许「与已点亮格 4-邻接」的格 → 采样结果**天然连通**；
- 终点约束：要求最后一个点亮格 = goal（或 BFS 到 goal 停）→ 「起点→goal 连通」结构性成立。

这一步和九条负结果直接对齐：**约束不该在 loss 里**。掩码解码把可行率从「学出来的」
变成「解码出来的」，可望直接到 ~100%（受 BFS 可达性限制）。

风险也明摆着：只用掩码，路径会退化成 BFS 最短路的重复（多样性塌到 1）。所以 P2 要配 P1：
**可行性由掩码保证，多样性由 primer 提供**（走哪条等长路径、密度、绕行风格）。

### P3 极小适配器承载 primer

primer 不重训三值主体（R5）：冻结生成器，把 `π` 通过输入旁路/软提示注入。
好处是参数量比全量重训小 2–3 个数量级、多个 primer 可共存（每个 goal 或风格一个），
推理时「选 primer」= 选风格；这也让 P1 的阶段 A 可以在单卡上跑很多轮。

## 3. 最小实验（机器可判）

| 编号 | 改动 | 判据 | 成本 |
|---|---|---|---|
| **E1** | P2 单独：给 `qat select` 加掩码解码（不重训） | 可行率 ≥90%（对照当前 0%）；同时报「不同路径数」看多样性退化到多少 | **已跑**：可行率 0% → 100%（结构性保证）；多样性由 loss 决定——`patch_swd` 下 61/64（n=256 时 225）、`patch_adv` 下 11/64（第十二条） |
| **E2** | P1+P3：`d=16` primer，冻结生成器，GRPO 训 2k 步 | 可行率 ≥90% 且组内新颖度（到训练集最近邻距离）比固定 primer 高 ≥20% | **已跑并判无效**（3k 步）：2048 样本 0% 可行，训练读数不可复现 |
| **E3** | R2 对照：goal 编码放输入**头部** vs **尾部**，各 5k 步 | 比「换 goal 的输出差」与可行率；若头部显著更高，说明 R2 的「读输入层布局」在自训小网上复现 | **已跑**（第十一条）：头部换 goal 输出差高 26.6%（t=4.13），可行率无差别（44.1% vs 43.0%）——方向复现、收益为零 |

失败回退：E1 若可行率上不去，说明能量定义本身有问题（先修裁判）；E2 若新颖度不涨，
说明 `π` 的维度/奖励权重没接对，退回 E1+随机 primer 做对照；E3 无论结果都入册。

## 4. 为什么这不是第十条重复

前九条都在**一个网络、一个损失**里挪约束（数据、步数、软条件、结构通道、可微惩罚、多 goal）。
本文三条是**结构外**的改变：

- P1/P3 把「生成过程的策略」交给第二个模型，奖励不回流产物生成器；
- P2 把「可行性」交给解码器（搜索/掩码），彻底离开 loss；
- E3 借用 R2 关于「输入层布局」的结论，检验我们的条件码位置是否本身就在拖后腿；
- R6 提供解释：SWD 是似然型项，梯度天然压过后验/能量项——这解释了负结果 #4 的「能量反升」。

## 5. 未证栏

- `π`（16 维过程码）**注入是通的**（E2 已验：有/无 primer 的样本逐样本都不同），但
  「µ 能否承载可行方向」尚未验证——E2 里训练带噪 11.7% 可行、π=µ 评估 0%。
- 「新颖度」的度量还没定：到训练集最近邻距离 / 组内两两 Chamfer / 感知距离，会显著改变结论。
- P2 的掩码解码只保证 4-邻接连通，不保证「路径不重复」；多样性计数已测（`patch_swd` 下
  61/64、n=256 时 225，第十二条），但**路径质量**（长度分布、几何塌缩、与 BFS 参考的距离）
  尚未测——提高 paths 计数回答不了这个问题。
- 只有 2D 8×8；3D 点云、旋转不变能量都没碰。
- R4 无正式论文、R5 的仓库与数字本机未核实（`api.github.com` 被判定为本机地址、拒绝抓取）；
  引用它们时只能当「线索」，不能当已证结论。
- E2 判无效（3000 步，`crates/qat/src/primer.rs`）：2048 样本 0% 可行，训练读数在评估
  口径下复现不出来。注意它沿用 `patch_adv`，而该 loss 本身就会让可行率恒 0（第十一条）。
- E1 已跑：掩码解码把可行率从 0% 抬到 100%，多样性 4 → 31；但 31 仍远少于 64 个 goal，
  「多样性靠 primer 撑起来」尚未验证。
- E3 已跑：条件码放头部让「换 goal 的输出差」高 26.6%（t=4.13），可行率不变（44.1% vs
  43.0%）——输入层布局影响条件被读到的幅度，不影响产物质量。
  读数见 [`CRAM-3D-DRIFT-RESULTS.md`](CRAM-3D-DRIFT-RESULTS.md) 第十、十一条。
