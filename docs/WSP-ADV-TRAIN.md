# 对抗训练：蓝方吃进化攻击样本——RowDropout 行级注入（2026-11-14）

#497 列的防御对策落地：红方进化攻击（kill-switch 行整行置零）的产物**作为
蓝方的训练信号**——对抗再训练时把红方点名的行轮换置零（RowDropout 注入），
强迫决策边界离开被攻击的单行。

## 1. 机制（`examples/adversarial_train/`）

```
基线 QAT → [红方进化攻击（行基因组，#497 同款）→ 攻击命中
           → 蓝方 A 对抗再训练（8 epochs，注入红方点名行的置零）
           → 蓝方 B 普通再训练（对照，无注入）
           → 同源攻击再打两个版本] × R 轮
```

- 注入实现：`train_one_epoch` 的 `zero_row` 参数——该 epoch 内被点名行整行
  置零后训练（前向/反向都在置零状态下进行），epoch 末恢复；
- **注入只作用 hidden 行**：输出层行置零 = 分类器熄火，不是「行冗余」要治
  的对象（边界）；
- 写回走正规编辑原语（`Edit::SetTrit`/`SetScale`——Net 无 mut 访问器，
  攻击者与防御者同一入口）。

## 2. 读数（3 轮，每轮 8 epochs 再训练，SMS spam）

| 轮 | 被攻击 F1 | 对抗再训练干净 F1 | **同攻击下对抗** | 同攻击下普通对照 |
|---|---:|---:|---:|---:|
| 1 | 0.0000 | 0.8295 | 0.0000 | 0.0000 |
| 2 | 0.0000 | 0.0000 | 0.0000 | 0.0000 |
| 3 | 0.0000 | 0.8804 | **0.9167** | 0.8370 |

**判读**：
- **round 3 出现鲁棒信号**：同源攻击下对抗再训练 F1 0.9167 > 干净 0.8804
  （RowDropout 让模型在被置零状态下仍保持决策）> 普通对照 0.8370；
- **单轮 8 epochs 不足**（round 1/2 同攻击仍 0）：决策边界的分散需要多轮
  累积——round 3 的模型带着前两轮的再训练权重；
- 基线与全程的 acc 0.13 是 spam 偏置（不平衡数据 + hinge，全预测 spam 时
  acc=13%），**F1 才是主指标**——偏置对攻防对比两侧同等存在。

## 3. 过程中的两个坑（对后续训练有用）

1. **全零工件反推的 QAT 再训练是死区**：对称初值（全 0 latent）+ 对称数据
   下，行内所有权重同步更新，Adam 打破不了行内对称——F1 恒 0（实测）。
   初始模型必须正常初始化（#492 的 absmean 教训的姊妹篇：初始化不仅管
   scale，也管「能不能从死区爬出来」）；
2. 输出层行的注入要跳过（置零输出行 = 熄火不是冗余训练）。

## 4. 复算

```bash
cargo run --release -p trit-wspace --example adversarial_train -- \
  --file <数据盘>/trit-data/sms-spam/SMSSpamCollection --rounds 3
```
