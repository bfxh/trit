# 高智商智能体任务标准

> 一句话：给智能体的不是「需求文档」，而是**可执行的验收程序 + 边界 + 起点**。
> 本文是主库对「把任务交给外部高能力智能体（Claude/GPT 级）」的硬标准；
> 不合格的任务包不派发。

## 0. 适用对象

- 能读全仓、跑命令、长时间自主执行的高能力智能体。
- **不是人类外包**：不写「请理解业务背景」，只写「读哪几个文件的哪几节」。
- 默认对方没有本会话上下文、没有本地环境记忆、不会来问问题。

## 1. 与「给人」的任务包的六个差异

| 维度 | 给人 | 给智能体 |
|---|---|---|
| 上下文 | 口头补全 | **自包含**：仓库、分支、起点 SHA、必读文件与行号 |
| 验收 | 「实现得差不多」 | **机器可判**：命令 + 退出码/计数/差分（DIFF 0、测试数、门禁列表） |
| 边界 | 默契 | **显式禁区**：不推 main、不抬预算台账、不降低三值判据、不碰指定面 |
| 失败 | 开会讨论 | **预写回退**：先写探针、不猜；负结果必须入册 |
| 交付 | 大 PR | **原子**：一个任务包一个 PR，可独立回滚 |
| 成本 | 人天 | **当量 + 墙钟 + 依赖**：允许并行几条线、需要什么环境 |

## 2. 难度分级（派发前必须标级）

| 级别 | 判据（全部满足） | 当量 |
|---|---|---|
| **S** | 跨 ≥3 个模块；引入新抽象/数据结构；有独立 oracle 差分或形式化性质；允许并鼓励负结果 | 3–10 天 |
| **A** | 跨 2–3 个模块；有现成对拍或可构造探针；判据清晰 | 1–3 天 |
| **B** | 单模块；扩展现有测试/表；无新抽象 | 0.5–1 天 |
| **C** | 文档、单点修复、配置 | <0.5 天 |

**S 级的四个硬门槛**（缺一不可）：
1. **独立 oracle**：官方实现/第二实现/穷举，不接受「自我一致性」。
2. **三值/不变量性质测试**：弃权不折叠、单调性、Kleene 定律等逐条断言。
3. **性能/预算门槛**：新能力不得使既有吞吐/内存退化超过阈值。
4. **失败负结果**：做不到的边界必须写清原因与复算命令，不许静默删减。

## 3. 任务包模板（直接复制）

```markdown
# 任务：<一句话，含验收对象>

## 级别与当量
S/A/B/C；预计墙钟；可并行度

## 起点
仓库 / 分支 / 起点 SHA / 必需环境（版本、依赖、样本）

## 必读（按顺序）
- 文件:行（只列真正需要的）

## 目标（G1..Gn）
每条写成「输入 → 输出/裁决」，可被命令判真假

## 非目标
明确不做什么，防止范围膨胀

## 验收（可复算）
```bash
<命令>
```
期望：<退出码 / 计数 / DIFF 0 / 测试数下限>

## 禁区
- 不推 main / 不改判据含义 / 不抬 module_budget 台账 / 不碰 <文件>

## 失败模式与回退
- 不可判定 → 先写探针，不猜
- 负结果 → 入 CHANGELOG + 文档，不许静默跳过

## 交付物
代码 / 测试 / 文档（三处同步）/ PR 描述含读数

## 自检清单
见 AGENT-TASK-STANDARD §6
```

## 4. 验收写法（唯一允许的形式）

- 只写**命令 + 期望输出/计数**；不写「看起来正确」「基本可用」。
- 差分必须给四态口径（MATCH / DIFF / SUBSET-GAP / OFFICIAL-ERR），
  且 `SUBSET-GAP` **逐条登记理由**。
- 三值系统必须显式声明：什么算 `True`、什么算 `False`、什么算 `Unknown`，
  以及 `Unknown` 如何传播。
- 测试数只增不减；预算台账只紧不松。

## 5. 反模式（出现即退回）

1. 只给目标、不给判据（「把 YARA 补完整」）。
2. 开放式优化（「性能再快一点」）——必须给基线与阈值。
3. 依赖聊天上下文/隐性知识。
4. 用「参考实现」代替独立 oracle。
5. 多个任务混在一个 PR。
6. 允许「先静默跳过、以后再说」——弃权必须记名。

## 6. 交付前自检清单

- [ ] 所有门禁命令已跑，读数贴在 PR 里（不是「本地通过」）
- [ ] 新增的 `Unknown` / `Unsupported` 都有原因字符串
- [ ] `module_budget.py` 未被抬高（拆文件而不是抬台账）
- [ ] CHANGELOG / 路线图 / 校准文档三处同步
- [ ] 负结果与未覆盖边界已入册（含复算命令）
- [ ] 一个任务包 = 一个 PR，可独立回滚

## 7. S 级示例

- `docs/AGENT-TASKS/S-YARA-FULL.md`：YARA 完整语义（表达式 + 模块对象 +
  官方差分 + 性质测试 + 性能预算）。这是「S 级长什么样」的参照实现。
