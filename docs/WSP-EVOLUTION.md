# 三值红蓝共同进化：想法进化的多智能体机制落到三进制安全对抗（2026-11-14）

把「想法进化」的多智能体机制（PROTEUS 式角色分工、化石记录、自我假设、
AB 双模型交替）落到三进制安全对抗上——**攻击策略本身就是三值基因组**。

## 1. 映射（`examples/evolution/`）

| 进化角色 | 本系统的实现 |
|---|---|
| PROMETHEUS（发散） | 对攻击基因组做 trit 翻转变异（1-3 位/代） |
| MOMUS（对抗批判） | **实测**适应度：对蓝方成员 0 施加基因组攻击，量 F1 打击量（噪声鲁棒：2 次评估取 min） |
| ANANKE（选择） | 精英保留（top-4）+ 按适应度选择父本 |
| HARMONIA（合成） | 逐位三值投票交叉（同向保留，分歧按假设偏向） |
| 化石记录 | 基因组 FNV 哈希 → **历史 fitness**（不重复评估但记住成绩） |
| 自我假设 | 每代统计精英策略的层分布 → 生成「哪层更承重」的可验证假设 → 下代变异偏向；命中 = 聚焦后 best fitness 上升 |
| AB 双模型 | 红方基因组进化 vs 蓝方防御集成（3 seed 投票）——每代双方完整适应度报告 |

**三进制不是装饰**：攻击策略 = 长度 129（128 hidden + 1 输出行）的三值
优先级向量；变异 = trit 翻转；交叉 = 逐位投票。基因组本身就是三值工件。

## 2. 读数（6 代，POP 12，k=16 行攻击，SMS spam 集成防御）

| 项 | 值 |
|---|---|
| 蓝方基线（3 成员集成） | acc 0.9356 / F1 0.7353 |
| **gen 0 即发现 kill-switch** | best_fitness **0.7353**（F1 全灭的基因型） |
| 化石记忆后 gen 0-5 | best_fitness **全程稳定 0.7353**（精英不丢失） |
| 最强攻击应用于单成员 | **F1 0.7500 → 0.0000**（acc 0.8652，全判 ham） |
| **最强攻击应用于集成** | **F1 0.7353 —— 完全扛住** |
| 化石拒绝 | 4/代（防重复评估/重复发明在工作） |

## 3. 过程中的三次设计修正（对后续进化实验有用）

1. **搜索空间必须包含致命行**：初版基因组只覆盖 hidden 128 行——而 #494
   已证明 kill-switch 在输出层。搜索空间不含答案，进化恒平（fitness
   0.005-0.01）。
2. **固定排序会永久挤掉关键行**：top-k 按行号排序时高索引行永远进不了
   攻击集——改成 +1 行随机采样（进化靠 fitness 选择，不靠排序）。
3. **化石的正确语义是「记住成绩」而非「拒绝再见」**：初版把已评估基因组
   直接排除出 scored——上一代的强基因下一代直接死亡。改成哈希 → 历史
   fitness 后，精英稳定保留（gen 0-5 全程 0.7353）。
4. **评估噪声要防**：目标行随机采样下单次评估可能漏掉关键行——MOMUS 取
   2 次评估的 min F1（best fitness 口径），否则精英被噪声误杀。

## 4. 防御判读（三段论终点）

| 防御 | 对进化最强攻击的 F1 |
|---|---:|
| 单成员（单点支配工件） | **0.0000** |
| 三成员集成投票 | **0.7353（无损）** |

**集成投票使 kill-switch 失效**：攻击摧毁 1/3 票，另两个独立训练的成员
仍正确投票。#495 列的防御对策在此定量验证。剩余风险：针对集成的**协同
攻击**（同时打三个成员的对应行）未做——那是下一轮的红方进化目标。

## 5. 未证栏

- 只测 SMS spam 判别式工件；DGA 归因模型上的进化未做；
- 假设机制只有层偏置一种粒度（命中率 0-1 波动大），更细的假设（行区间/
  特征维度）未做；
- 蓝方防御只有「换 seed 集成」，对抗训练（用进化攻击样本再训练）未做；
- 红方基因组只编码行选择，trit 级定位的基因组化未做。
