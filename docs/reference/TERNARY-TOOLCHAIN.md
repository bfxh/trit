# 三进制构建工具链（TTIR → TRB2）——定位、论文依据与边界

> 状态：**M0–M3 + 2026-11-08 补齐的 6 项遗留全部落地**（`trit-build`），有测试/实测钉住。
> 规则来源：`docs/positioning/TERNARY-BOUNDARIES.md` 的 A/B/C/D 记账；任何"更快/更省"必须给二进制基线。
> 本文里的论文都经过 OpenAlex 核验（DOI 可查），未核验的一律标"未证"。

## 0. 一句话

**不重写 LLVM，重写"三进制独有的那一层"。** LLVM/Rust 负责机器码、链接、OS、包管理；
本工具链负责三值语义（K3/Ł3/B3）、`X` 的传播与精确复核、基 3 打包与 GF(3) 检错、
以及三值产物（`TRB2` / 双导轨 Verilog / WGSL 内核）的生成与增量构建。

## 1. 论文与技术（哪些真能借）

| 来源 | DOI / 标识 | 借什么 | 不借什么 |
|---|---|---|---|
| LLVM（Lattner & Adve, CGO 2004） | `10.1109/cgo.2004.1281665` | 分层 IR + pass 契约 + "分析结果可复用" | 二进制后端（SSA、寄存器分配、指令选择） |
| MLIR（CGO 2021） | `10.1109/cgo51591.2021.9370308` | dialect 分层的 lowering 结构：TTIR → 目标方言 | 通用 GPU/张量方言栈 |
| egg（POPL 2021） | `10.1145/3434304` | e-graph 等价饱和做三值代数重写 | 直接套规则：K3 的规则必须逐条枚举 3^n 自证 |
| BitNet b1.58（2024） | `arXiv:2402.17764` | 三值权重的存储与推理形态（MOD/GGUF 入向） | 训练/推理性能结论 |
| 平衡三进制序列压缩（TVLSI 2019） | `10.1109/tvlsi.2019.2906678` | 基 3 打包/解包的码率与解压路径 | 硬件实现细节 |
| 组合平衡三进制数制（2018） | `10.7753/ijcatr0707.1008` | 三进制整数表示的动机 | 性能对比（无同口径基线） |
| Setun（Brusentsov, 1958） | 历史文献，无 DOI | 只作"三值机器曾真实存在"的动机 | **不作性能证据**（器件与今天不可比） |

结论：可借的是**结构**（分层 IR、pass 管线、e-graph、基 3 打包），
不能借的是**二进制后端的优化结论**——那套东西的收益建立在 2 的幂寻址和固定位宽上。

## 2. 三进制独有的是什么（先分类再说话）

- **A 语义**：`X` 是原子值。K3 下 `a & ~a = 0`（确定），B3 下才是 `X`；这个区分是布尔 + 错误码压不出来的。
- **A 复核**：任何"优化"都必须能被 3^n 穷举或精确传播证伪；本工具把"化简后不等价"当**构建失败**，不是警告。
- **A 打包**：5 trit/字节 = 243 ≤ 256（1.6 bit/trit），比双导轨 2 bit/trit 省 20%，比理论下限 1.585 只差 0.9%
  （这项在 `trit-codec` 已实现；M0 因发布图约束先用双导轨，见 §3）。
- **B 税**：宿主是二进制，运行前必须解包/查表；"原生三值器件"不存在于本机。
- **D 无关**：缓存、增量、并行调度、错误恢复——任何进制都要付。

## 3. 架构：TTIR-0 → M3（全部已实现）

```text
.tri / Verilog 子集
      │ 前端：解析 + 预算检查（3^n ≤ 上限）
      ▼
   TTIR-0：AST（K3/Ł3/B3 语义可选）
      │ pass 1：化简（代数规则，标出用到的规则）
      │ pass 2：e-graph 饱和重写（规则逐条自证；代价模型提取）
      │ pass 3：精确复核（穷举等价）
      ▼
   产物层
   ├── truth.csv      真值表（人读/对拍）
   ├── truth.tritbin  TRB2 v3：头 + 变量名 + 5 trit/字节 + GF(3) CRC-3
   ├── lookup.c       主机查表函数（交给 cc/rustc 编译 —— 边界示范）
   ├── direct.c       主机直算函数（`--backend direct|both`：线性 IR + 交换律 CSE + 常量折叠/恒等式化简 + 化简内常量否定 + CSE（含 And/Or/Xor2 结合链）+ DCE + 变量/常量叶子直写（变量复用 ≤5 次；≥6 次保留一条读取）+ 单用节点沿单用边内联（不封顶；调度与表达式展开都用显式栈）+ 根节点直接返回；取反写一元负号；二元调用在 `trit_bin` helper 与逐调用表索引间按整篇字节数择优；`.tri` 表达式与 Verilog 网表共用，不展开 3ⁿ 表）
   ├── design.v       双导轨 Verilog（K3/Ł3/B3 均支持）
   ├── design_tb.v    自检 testbench + expected.mem（`--verify-hdl`）
   ├── truth.wgsl     WGSL 查表内核 + truth.gpu.bin（2 bit/trit，`--emit-gpu`）
   └── build.json     输入/选项/产物哈希/复核结论
      │
      └── 驱动：内容哈希缓存（FNV-1a）+ `--check` 产物完整性
```

**产物格式（TRB2）**：
- v2（旧）：`TRB2` | version=2 | algebra u8 | nvars u8 | len u32 LE | 载荷。
- v3（现行）：`TRB2` | version=3 | algebra u8 | nvars u8 | len u32 LE | names_hash u64 LE |
  `nvars × (name_len u8 | UTF-8 名字)` | 载荷。
- 载荷 = `len` 个输出 trit ‖ CRC-3（3 个 trit），按 5 trit/字节小端打包（权重 1/3/9/27/81）。
- `names_hash` 是名字段的 FNV-1a 64；解码 v2 时列名回退 `v0..vN`。名字只允许字母/数字/`_`/`$`，
  避免写回 CSV 表头或 C 注释时逃逸。

**规范形（硬规则）**：末字节里没用到的 trit 槽必须为 0。否则同一张真值表会有多个字节串
（实测 27 种），「内容哈希 = 身份」就不成立。Rust 解码器、C 运行时（`TRIT_ERR_CANON`）
与 red-team 的解析器都按这条契约拒绝非规范编码。

**为什么 M0 用双导轨、M2 才换基 3**：`trit-codec`（5 trit/字节 + GF(3) CRC-3）是
`publish = false` 的实验层，而本仓发布图门禁**禁止实验 crate 互相依赖**（`trit-build` 也是实验层）。
M0 先做"语义/复核/增量"，打包密度留到 M2。

**M2 的取舍（如实）**：既没有把打包下沉 `trit-core`，也没有依赖 `trit-codec`，而是在
`trit-build/src/trb.rs` 写了一份**同构的精简实现**。代价是同一格式有两份代码，必须靠
`runtime/trit_runtime.c`（第三份、独立语言）交叉验证来兜底；codec 稳定后应统一，删掉这里的副本。

## 4. 现在能跑什么（实测，2026-10-25；TRB2 v3 行更新于 2026-11-08；直算行更新于 2026-11-26）

```bash
# 源文件：第一行非注释内容 = 表达式
printf '# demo\n(a & b) | !c\n' > demo.tri
trit build demo.tri --out out
trit build demo.tri --out out          # cached=true
trit build demo.tri --out out --check  # 校验产物哈希
```

实测结果（`crates/trit-cli/tests/build.rs`，3 条集成测试绿）：

| 项 | 证据 |
|---|---|
| 3 变量 → 27 行真值表 | `truth.csv` 28 行（含表头） |
| `TRB2` 大小 | v3：19 字节固定头 + 名字段 3×(1+1) + 6 字节载荷 = **31 B**；v2（无名）17 B；M0 的 TRB1 是 35 B |
| 变量名 | v3 存原名，`--decode` 重建的 CSV 表头与原表一致；v2 回退 `v0..vN` |
| 主机对拍 | `lookup.c` 用 gcc 编译后 27/27 行与 `truth.csv` 一致 |
| 直算对拍 | `direct.c`（`--backend direct --verify-c`）用 cc 编译后 **531,441/531,441** 行与 `truth.csv` 一致（12 变量，本机 0.9 s） |
| 直算 IR 优化 | 交换律规范化后镜像子式共用一个节点；`∧` / `∨` 再展平结合链、去重、排序后重建，镜像结合共用一条链；化简后再按结构 CSE 合并重新出现的同构子式；`prune_dead` 压缩孤儿并重编号；`((a & 1) & b) \| (a & b)` 由 7→3 条语句，`((a & c) & b) \| (a & (b & c))` 由 8→5 条、`direct.c` 705 B；12 变量仍 **531,441/531,441** 行通过 |
| Verilog 直算 | `.v` 源也能开 `--backend direct` 或 `both`：从选中输出反向 DFS，只降扇入锥（其它输出不进 IR）；`NAND/NOR` 落 `Not(And/Or)`、`BUF` 直接别名、`XOR2` 单独一张表；K3/Ł3/B3 各 27/27 行 cc 对拍 |
| 直算常量折叠 | 操作数全是常量的节点按 `Algebra` 现算（`Xor2` 按 `GateKind::XorClassic`），折叠后再 `prune_dead`；全常量树只剩一条 `Const` 语句，`direct.c` 不再注册任何算子表 |
| 直算恒等式化简 | 三种代数通用 `x ∧ T = x`、`x ∨ F = x`、`¬¬x = x`、`x ∧ x = x`、`x ∨ x = x`；K3/Ł3 额外做吸收律 `x ∧ F = F`、`x ∨ T = T` 与格吸收律 `x ∧ (x ∨ y) = x`，B3 因 `U ∧ F = U`、`F ∧ (F ∨ U) = U` 保留原式。别名压平后 DCE；同一 3 输入网表 16→14→12 条语句、1331→1267→1203 B（K3） |
| 直算格吸收链 | K3/Ł3 的格吸收沿同算子链传递：`Or` 沿 `Or`、`And` 沿 `And` 迭代找 `x`，遇异算子停手；`a & (a \| b \| c)` 线性 IR 6→1 条、`direct.c` 395 B、不注册算子表。B3 同式仍 6 条、806 B，保留两张表 |
| 直算公因子提取 | 三代数共同的分配格反向式 `(a ∧ b) ∨ (a ∧ c) = a ∧ (b ∨ c)` 与对偶 `(a ∨ b) ∧ (a ∨ c) = a ∨ (b ∧ c)`；只认两侧同算子节点直接相同的操作数，子式里埋的因子不猜。`(a & b) \| (a & c)` 线性 IR 6→5 条、`direct.c` 767 B；B3 同式 5 条、766 B |
| 直算 Xor2 常量律 | 按 `GateKind::XorClassic.eval`：`x ^ 0 = x`、`x ^ 1 = ¬x`、`x ^ X = X`；`x ^ x` 不化简（`X ^ X = X`）。Verilog `a ^ 1'b0` 只剩一条取变量语句、不注册 `T_XOR2` |
| 直算 Xor2 结合链 | `Xor2` 三代数都结合（任一操作数为 `U` 即 `U`，全已知走布尔异或）：展平嵌套链、按下标排序、重建左深链并共享前缀；**不去重**，`x ^ x` 在 `x = U` 时仍是 `U`。展平记录已展开内部节点，`Xor2(y, y)` 不把 `y` 展两次；镜像链 `((a ^ b) ^ c) ^ (a ^ (b ^ c))` 从 8→6 条语句、`direct.c` 751→667 B（K3）、752→668 B（B3），三代数 `--verify-c` 27/27 |
| 直算连接词常量律 | `⇒` / `⇔` 按代数分派：K3/Ł3 做 `x ⇒ T`、`F ⇒ x`；三代数共用 `T ⇒ x = x`、`x ⇔ T = x`；Ł3 额外 `x ⇒ x = T`、`x ⇔ x = T`，K3/B3 额外 `x ⇒ ¬x`、`¬x ⇒ x`、`x ⇔ X = X`；B3 的 `X ⇒ T`、`F ⇒ X` 保留原式 |
| 直算强加常量律 | `⊕` 按代数分派：K3/B3 的已知值按合取，做 `x ⊕ T = x`、`x ⊕ X = X`；Ł3 是饱和加法，做 `x ⊕ F = x`、`x ⊕ T = T`、`x ⊕ ¬x = T`；变量 `x ⊕ X` 在 Ł3 保留 |
| 直算否定归一 | `¬¬x = x` 与德摩根回收 `¬(¬a ∧ ¬b) = a ∨ b`、`¬(¬a ∨ ¬b) = a ∧ b`，三代数通用；只回收两侧都已取反的 4 节点形状为 1 节点，`!(!a & !b)` 的线性 IR 6→3 条语句、`direct.c` 631 B，单侧取反保留 |
| 直算德摩根链归一 | 在恒等式化简之前把 `¬(¬a ∧ ¬b ∧ ¬c)` 整链落 `a ∨ b ∨ c`，对偶落 `And`；只在 `Not` 直接盖住同算子链且每个叶子都是 `Not` 时命中，任一叶子不是 `Not` 就整棵保留。三代数 3×3×3 逐格对拍；`!(!a & !b & !c)` 线性 IR 9→5 条语句、`direct.c` 698 B（K3）/ 699 B（B3），不注册 `T_NOT` |
| 直算 B3 补元消去 | 只在 B3 做 `x ∧ (¬x ∨ y) = x ∧ y`、`x ∨ (¬x ∧ y) = x ∨ y`，四种操作数顺序都认；命中后重建 `x ∧ y` / `x ∨ y`，不是别名到单个操作数。K3/Ł3 在 `x = U` 处有反例 `U ∧ (U ∨ F) = U ≠ U ∧ F = F`、`U ∨ (U ∧ T) = U ≠ U ∨ T = T`，IR 逐节点保留；`a & (!a \| b)` 线性 IR 5→3 条语句、`direct.c` 636 B，只剩 `T_AND` |
| 直算 B3 毒值吸收 | 只在 B3 做 `x ∧ X = X`、`x ∨ X = X`：`U` 沾上即传染。`a & X` / `a \| X` 从 3 条语句塌成一条 `Const`、`direct.c` 386 B、不注册 `T_AND` / `T_OR`；K3 同式仍 3 条语句（629 B / 623 B），Ł3 保留 `T_AND` / `T_OR` |
| 直算化简内常量否定 | `Not(Const)` 在化简内立即折成 `Const`，父节点本遍即可看到常量；否则父节点已错过 B3 毒值吸收。B3 网表 `(~(a & 1'bx)) & b` 从 3 条语句（550 B，含 `T_AND`）收成一条 `Const`、308 B、不注册表；K3/Ł3 同式保留 `T_AND`，取反走一元负号、不再注册 `T_NOT`，三代数 `--verify-c` 均 9/9 行 |
| 直算取反锥内联（第四十四轮） | 渲染时从 `Not` 出发，把单用子式沿单用操作数递归并进父语句（从 `Not` 的操作数算起最多 3 层）；命中扇出或多用即停，子式仍单独落变量，网表扇出不复制。内联后临时变量重编号为连续 `t0..tn`。混合 `nand/nor/xnor` 网表 9 条语句、1113 B（K3）/ 1112 B（B3）；单门 `nand g(y,a,b)` 3→1 条、732→692 B（B3 731→691 B）；单门 `not g(y,a)` 2→1 条、506→486 B（B3 507→487 B）；`~((a \| b) & c)` 5→1 条、862→782 B（B3 861→781 B）；`a ^ 1'b1` 2→1 条、506→486 B；三代数 `--verify-c` 全过 |

| 直算根节点直返（第四十八轮） | 根节点不落临时变量，直接由 `return` 展开；其余单用内联规则与深度 3 不变。`(a & b) \| c` 661→641 B、1→0 条；`((a & b) \| c) & (d \| e)` 716→696 B、1→0 条；`((a => b) <=> (!a \| b)) ^ c` 773→753 B、2→1 条；11 变量混合式 1273→1251 B、11→10 条；深链 784→764 B、3→2 条；`!a` 486→466 B、1→0 条；三代数 `--verify-c` 3^11 行全过 |
| 直算取反去表（第四十九轮） | `Not` 直接写一元负号 `-(...)`，不再生成 `T_NOT[3]` 或 `trit_not()`；三种代数的 `not` 在 `-1/0/1` 上都等价于算术取负。`!a` 466→348 B、1→0 条；11 变量混合式 1251→1133 B、10 条不变；含存活取反的文件少 118 B（表 + helper + 空行），无取反文件不变；新增 `direct_c_size.rs` 六样例字节上界，三代数 `--verify-c` 3^11 行全过 |
| 直算单二元调用展开（第五十轮） | 折叠后全文只有一个二元节点时省掉 `trit_bin` helper，直接写 `T_X[(a + 1) * 3 + (b + 1)]`；两个及以上调用仍共用 helper。`a & b` 557→448 B、`a \| b` 551→442 B、`a => b` 555→446 B、`a <=> b` 558→449 B、`a ^ b` 555→446 B；`a & b \| c` 两调用保持 641 B；单调用样例统一少 109 B；三代数 `--verify-c` 单算子与 3^11 行全过 |
| 直算否定对偶与 helper 择优（第五十一轮） | 化简层把 `x ⇒ F` 改 `¬x`、`¬x ⇒ ¬y` 反证 `y ⇒ x`；`x ⇔ F` / `F ⇔ x` 改 `¬x`、`¬x ⇔ ¬y` 去双层取反，同一 `¬x ⇔ ¬x` 在 Ł3 折 `T`。渲染层同时生成 helper 版与表索引版函数体，按整篇字节数选短者；语句右值也跟随所选版本。`a <=> 0` 442→347 B、`(!a) <=> (!b)` 455→449 B、`(!(a & b)) => (!(c \| d))` 671→582 B；`(a & b) \| c` 641→545 B、`((a & b) \| c) & (d \| e)` 696→614 B、11 变量 1133→1093 B、深链 764→689 B；dense 12 项仍选 helper（1430 B，强推表索引 1446 B）；三代数穷举对拍 |
| 直算叶子临时变量消除（第五十二轮） | 变量/常量叶子不再单独落 `int8_t tN = vars[i];`；变量复用 ≤5 次直接写 `vars[i]`，≥6 次保留一条读取（临时语句约 25 B、每次引用省 5 B，6 次回本），常量叶子总是直写。非叶子仍按单用/深度 3 规则内联。11 变量 1093→893 B、深链 689→669 B、dense 12 项 1430→1254 B；其余 fixtures 不变；三代数 `--verify-c` 11 变量与 dense 全过 |
| 直算单用内联取消深度封顶（第五十三轮） | 内联决策删掉 3 层上限：凡 `uses==1` 的非叶子节点都沿单用边并进父表达式，直到叶子；扇出/多用节点仍单独落一条语句，网表扇出不复制。调度与表达式展开都改用显式栈，两万层单用链不再递归。每个单用临时语句比它的引用多至少约 20 B，所以全量内联在字节上严格更短，代价是深链和密集网变成更长的单条 `return` 表达式。深链 669→649 B、dense 12 项 1254→1174 B、高复用 9 变量样例 1003→963 B；11 变量混合式仍 893 B；三代数 `--verify-c` 上述样例全过 |
| 增量 | 同源二次构建 `cached=true`，不重写产物 |
| 完整性 | 篡改 `truth.tritbin` 后 `--check` 退出非 0 |
| 复核 | 化简不等价 ⇒ 构建失败，不写任何产物 |

**编辑器支持（M0）**：`trit-lsp` 是 `.tri` 的语言服务器——诊断（与上面的前端同规则）、
运算符悬停（按当前三值语义现算 3×3 真值表）、补全、文档符号。它不复制语法/语义：
解析用 `trit_core::Parser`，真值表用 `trit_eval::eval`。用法见
[crates/trit-lsp/README.md](../../crates/trit-lsp/README.md)。

## 5. 继续靠 LLVM / Rust 的部分（刻意不自己写）

| 职责 | 归谁 | 理由 |
|---|---|---|
| 机器码生成、寄存器分配、指令选择 | LLVM / Cranelift | 与基数无关，重写只是更差 |

| 加密、网络、GUI | 现成库 | 与进制无关 |

**判据**：如果某项在三进制世界里和二进制世界里"要做的事一样"，就不该自己写。

## 9. 双轨并行：谁先、谁吃剩余（`--manifest`）

用户 2026-10-25 的取舍：**三进制轨（本工具）优先**，二进制轨（cargo/rustc/LLVM）用剩余槽位并发，
双方都别等对方；支持谁由 `--prefer` 决定。

| `--prefer` | 谁先 | 行为 |
|---|---|---|
| `ternary`（默认） | 三进制轨 | 三进制待办且槽位未满 ⇒ 只派三进制；二进制只在三进制排空或槽位已满时上 |
| `binary` | 二进制轨 | 镜像：三进制吃剩余 |
| `balanced` | 清单顺序 | 单 FIFO，按提交顺序 |

**不做抢占**：二进制任务跑起来不会被打断（cargo 没有安全挂起点）；
"优先"的含义只是**不派发**，不是强杀。

清单（路径相对清单文件）：

```json
{"jobs":[
  {"name":"a","kind":"ternary","source":"a.tri"},
  {"name":"lib","kind":"binary","cmd":["cargo","build","-q","-p","trit-core"]},
  {"name":"b","kind":"ternary","source":"b.tri","out":"out/b"}
]}
```

```bash
trit-build --manifest jobs.json --jobs 4 --dry-run        # 只看分配
trit-build --manifest jobs.json --jobs 4                  # 真并行
trit-build --manifest jobs.json --jobs 4 --prefer binary  # 反过来支持二进制
```

实测（本机，7 个任务 / 4 槽位：6 个 `.tri` + 1 个 `cargo build -p trit-core`）：

| 指标 | 值 |
|---|---|
| wall | **171 ms** |
| busy（各任务耗时之和） | 205 ms |
| speedup = busy/wall | 1.2× |
| 三进制单任务 | 4–8 ms（与 163 ms 的 cargo 并行，不被阻塞） |
| 失败 | 0 |

**如实说明**：M0 的三进制任务只有毫秒级，所以"总加速"只有 1.2×——收益体现在
"cargo 跑 163 ms 期间，6 个三进制构建已经全部完成"，而不是把 cargo 变快。
两侧都重（大网表 + 大 crate）时才有明显加速，那要等 M1 的真实工程。

## 12. M3 实测：位并行算表 + e-graph 重写

```bash
trit-build big.tri --out out        # 12 变量 = 531,441 行
```

**位并行**：每轮同时算 64 组赋值。门语义**不手写公式**——先从 `Algebra` 取该门在 3×3
输入组合上的结果表，再按最小项铺到 pos/neg 位平面。K3/Ł3/B3 共用一份代码，
Ł3 的 t-norm、蕴含这些容易写错的地方不需要人工推公式。
行序是硬约束：`code` 以 3 为基、`0→False / 1→Unknown / 2→True`（与 `truth.csv` 的 -1/0/1 对齐）。
`trit-core::bits::Evaluator` 用的是 1↔2 对调的另一套行序，**没有复用它**。

**e-graph**：规则**先自证、后加载**——对规则里出现的 ≤3 个变量穷举 3^k 组取值，
用生产同一份 `trit_eval::eval` 比较左右两边，任何一组不等这条规则就不进图。
因此同一张规则表可以喂三种语义：蕴含消去在 K3 成立、在 Ł3 不成立，会自动只出现在 K3 的规则集里。
重写跑到**不动点**（无新合并即停；`--egraph-rounds` 上限、`--egraph-node-limit` 兜底），
提取支持 `--cost nodes|gates` 两种代价模型；整条链再用穷举复核一次。

实测（release，本机 24 逻辑核，2026-11-08）：

| 项 | 读数 |
|---|---|
| 12 变量算表 | 标量 **297 ms** → 位并行 1 线程 **23.7 ms** → 24 线程 **3.74 ms**（对单线程位并行 **6.3×**） |
| e-graph | 饱和 true；清单记录 rounds / e-nodes / cost / nodes；默认 64 轮上限通常 2–3 轮收敛 |
| 化简 / 重写 / 等价复核 | 23 µs / 164 µs / 11.6 ms |
| `truth.csv` / `lookup.c` 序列化 | 59 ms（19.6 MB）/ 19 ms |
| CLI 端到端（12 变量） | release **0.17–0.23 s**（多次运行落在 CSV/写盘噪声内，不主张 E2E 加速） |
| 产物 | 与 M2 **逐字节相同**（`truth.csv` / TRB2 / `lookup.c`） |
| 规则集 | 18 条；K3 过 17 条，Ł3 少 `implies-elim`，B3 少吸收律——全部逐条自证 |

**顺带修正的语义坑**：`Expr::Xor` 在本仓是**强加法 ⊕**，K3/B3 下 U 传染
（`F ⊕ U = U`，而格运算 `F ∧ U = F`）。M2 的双导轨导出按布尔异或写，导出的 `design.v`
与 `truth.csv` 对不上；M3 修正并补了 `^` 的导出对拍用例。

**M3 仍未做（如实）**
- 算表已不是瓶颈：端到端时间在 CSV / `lookup.c` / FNV 哈希 / 写 19.6 MB 盘，未优化。
- 多线程按行切块，没有按 e-class 切分；e-graph 仍无 e-matching 索引，大表达式重写开销未测。
- 代价模型只有 nodes/gates 两档，没有面积/延迟/功耗权重。

## 7. 不做什么

- **不做二进制后端**：没有三值硬件之前，ILP/寄存器分配/向量化都该留给 LLVM。
- **不做通用语言**：`.tri` 只是一种“可复核的三值表达式”，语法故意最小；扩展要等真实 Verilog 前端。
- **不承诺速度**：本工具的收益是“更小、可查错、可复核”，不是“更快”。任何速度声明必须同机基线。
- **不把 `X` 当 `-1`**：这是 `TERNARY-BOUNDARIES.md` 的硬规则，工具层同样适用。

## 8. 未验证清单

- 真实 Verilog 工程的 M1 前端（端口/时序/多驱动）未做；当前只覆盖组合逻辑子集。
- `direct.c` 的 Verilog 链路同样只覆盖组合子集与单一选中输出（多输出需 `--output`），
  不做综合/门级优化；网表里有多个驱动或组合环时显式报错，不猜。
  常量折叠只折「操作数全是常量」的节点；化简内把 `Not(Const)` 立即折成常量，让父节点本遍看到它，
  不另设回折 pass，也不把 `U` 推广到其他二元算子；恒等式化简做三代数通用的
  `x ∧ T`、`x ∨ F`、双重否定、幂等律，K3/Ł3 额外做吸收律与格吸收律，B3 的反例
  （`U ∧ F = U`、`F ∧ (F ∨ U) = U`）明确保留原式；格吸收只沿同算子链传递，
  遇异算子停手，不猜「子式里含 x」；公因子只提两侧直接相同的操作数，不往子式里挖；B3 另有只在毒值语义成立的
  补元消去 `x ∧ (¬x ∨ y) = x ∧ y`、`x ∨ (¬x ∧ y) = x ∨ y`，K3/Ł3 不适用；B3 的
  `x ∧ X` / `x ∨ X` 直接吸收成 `X`，K3 的 `F ∧ X = F` 与 Ł3 的 `F ∧ X = F` / `T ∨ X = T`
  保留原式；`Xor2` 只做常量律，不做 `x ^ x`；
  `⇒` / `⇔` 只做减少节点的常量律，B3 的 `X ⇒ T`、`F ⇒ X` 与 Ł3 的 `x ⇒ ¬x` 保留原式；
  `⊕` 只做单位元/吸收元，K3/B3 的 `x ⊕ F` 与 Ł3 的 `x ⊕ X` 保留原式；二元德摩根只回收
  两侧操作数都已取反的形状，单侧取反仍保留 `Not`；三叶以上的同算子链由化简前的
  `negchain` 整体归一，但要求每个叶子都已经是 `Not`，不猜子式里含取反；它在 CSE 之前跑，
  链遍历对同算子节点做 visited 去重，重复子式不会反复下钻，代价随当前外层 `Not` 的链节点线性；
  结合链规范化：`∧` / `∨` 展平、去重、排序；Verilog `^`（`Xor2`）只展平、排序、共享前缀，
  不去重；不把 `⊕` / `⇔` 当成可结合的算子。渲染阶段从每个会发射的节点出发把
  `uses==1` 的子式沿单用操作数并进父语句，不设深度上限；根节点直接 `return` 展开；
  命中扇出或多用即停；变量/常量叶子直接重写，变量复用 ≥6 次时保留一条读取，
  剩余临时变量重编号为连续 `t0..tn`；取反直接写一元负号，不再发 `T_NOT`。全量内联的
