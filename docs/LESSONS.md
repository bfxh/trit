# 经验与负结果

> 这份文档记两件事：三进制的**代价**，和我们试过并已证伪/已修掉的路。
> 每条都尽量给可复算入口；不能在仓库内复现的会标"未复现"，不当结论用。

## 1. 三进制不是免费的（代价清单）

| 代价 | 数字 | 复算入口 |
|---|---|---|
| **浮点精度** | 同比特存储下，三值浮点相对误差上界是二进制的 **3 倍**（`3^{1-p}` vs `2^{-B}`，白丢约 1.58 bit） | `crates/trit-float`（`trit-float stats`） |
| **算术** | 打包三进制的加法/乘法要逐 lane 进位，远慢于 i64；本仓因此**只做逻辑 + 位并行点积**，不做打包算术 | `crates/trit-dot`、[CHANGELOG](../CHANGELOG.md) |
| **CPU 三值内核带宽** | 掩码 21.5、tryte 24.9 GB/s vs 本机 33 GB/s 访存墙（65–75%） | `crates/trit-ops/README.md` 实测一 |
| **tryte 的适用范围** | 49152 行时仍比掩码慢 5.5%；反超点已抬到 65536 行 | `bench --pair 掩码 tryte` |
| **GPU subgroup** | 1.341 ps/MAC vs SIMT 0.298（**4.5× 慢**） | `crates/trit-gpu/README.md` |
| **GPU 2-popcount** | 比 3-popcount 慢 1.9%（少一次 popcount 抵不过额外移位） | `crates/trit-gpu/README.md` |
| **训练（STE）** | 三个变体在 2×3 无噪任务上同分（都在第 99 步达标），选型需要更大/带噪任务 | `crates/trit-train` |
| **生态** | 没有原生三值硬件；权重必须靠 QAT 才能保住质量（推理端省字节，训练端付代价） | [docs/DESIGN.md](DESIGN.md) |

## 2. 已证负结果（别重复试）

- **打包三进制算术**：取反 1.48×、加法 133×、乘法 3348× 慢于 i64（**未复现**：来自仓库外的
  打包算术原型，未随本仓发布；本仓不依赖这条结论做设计）。
- **GPU 2-popcount**：−1.9%（2026-10-25，说明该内核不是 popcount-bound）。
- **GPU subgroup（SPIR-V 路径）**：16×32/warp，1.341 ps/MAC，4.5× 慢于 SIMT。
- **split-K 单独使用**：0.120–0.122 ps/MAC，输给 3-popc 的 0.101–0.103。
- **K 段 16**：预评估要多 128 次 `workgroupBarrier`/CTA，没做。
- **tryte 小行数整表**：0.40×（已修：拆表 2+3，现 1.07×）。
- **fp16 存储变体**：只有 −16%，是带宽账的一部分，不是免费午餐。
- **位平面算术加法**：进位链串行，不做；位平面只做逻辑与强加法。

## 3. 测量经验（比结论更值钱）

1. **只信相邻配对**。同一段代码换个位置，读数能差 25–40%；`bench --pair` / 交替轮次才有判决力。
2. **小规模会把结论测反**。位平面 ALU 在 1 M trit 时，8 线程（5.4 Gop/s）比单线程（14.9 Gop/s）
   还慢——线程创建开销压过计算；16 M trit 才看到真实扩展性。
3. **计时建表必须用差分法**。直接给建表循环计时会被死存储消除优化掉，测出来不到真实值的一半。
4. **表内横向排名不可当精确排名**。分形状表是顺序测量，只能看量级。
5. **负结果要连同判据一起记**。"慢了多少、靠什么判慢、什么条件下"三者缺一，结论就不能复用。
6. **软件预取对顺序访问没有收益**（±5% 噪声内）——硬件预取器已经覆盖；别拿它当性能优化交差。

## 4. 工程经验

- **`enable f16;` 是模块级开关**：放进共享着色器，会让不支持 `SHADER_F16` 的 adapter
  连 f32 基线都建不出来（真实事故，已拆成独立 `matmul_f16.wgsl`）。
- **跨架构必须验编译**：x86_64 内建函数需要标量回退，否则 arm64 上直接编译失败。
- **文件行数不等于结构**：一个 786 行的文件里可以有 655 行的单函数；拆模块时要按职责看，
  而不是只看行数。
- **文档用仓库相对路径**：不写本机绝对路径，别人拿到仓库就能点开。
