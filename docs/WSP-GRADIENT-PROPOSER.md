# 从手工特征到梯度提议器

## 1. 现状

`learned` 用 16 维手工特征 + 线性打分器（SGD + L2），标签来自 `analyze` 的实测
`gain`。它能工作，但：

- 特征是人选的，不知道哪些统计对当前工件重要；
- 线性模型不能表达特征交互；
- 标签要跑全量 `analyze`，成本高；
- 没有用权重本身的梯度。

## 2. 三条可走的路

### A. 梯度知情排序（最小改动，建议先做）

对每个 oracle 样本，把三值权重松弛为 f32（或直接对 sign 用 STE），算损失
`L = Σ (raw_output - target)^2`（或交叉熵）；反向传播得到 `∂L/∂w[r,c]` 与
`∂L/∂b[r]`。提议分数 = `|∂L/∂w|`（只对当前 trit 可改的方向），与 `analyze` 的
top-K 对拍。

- 前向：三值权重 + 符号激活；输出层保留 f32 raw。
- 反向：符号激活的导数用 STE（`d sign(x)/dx = 1`，或截断到 `|x| < 1`）；
  权重导数 `∂L/∂w = δ_row · x_col`；按样本累加平方。
- 不需要训练任何参数；一次反向传播得到所有候选分数，比 `analyze` 的 N 次前向便宜。
- 风险：STE 梯度与离散编辑的真实收益不完全一致；要用 top-K 命中率验证。

### B. 可微特征 + MLP（中等）

把手工特征换成可微小网络：

- 输入：每层输入 `x`、`w`/`b`/`scale` 的局部统计、`∂L/∂w`；
- 1 隐层 MLP（16→32→1），手写前向/反向；
- 损失：pairwise ranking（正样本 `gain>0` 排在负样本前）或 MSE；
- 只训练打分器，不写回权重。

### C. 端到端可微代理（最大）

训练一个“编辑收益预测器”：

- 动作 `a ∈ {+1,0,-1}` 的 one-hot 输入；
- 目标：实测 `gain` 或 `Δloss` 的可微代理（用松弛权重算）；
- 反向传播通过特征提取器；
- 推理时对每个候选打分，库复核。
- 难点：真实 `gain` 是黑箱，只能蒸馏 `analyze` 或使用松弛代理。

## 3. 建议路线

1. **A 先做**：一次反向传播 vs N 次前向，成本差异最大；与现有 `analyze` 直接对拍。
2. 把 `|∂L/∂w|` 加入 `learned` 的 16 特征（第 17 维），重训线性模型，看 top-K 是否提升。
3. 若线性仍不足，再上 B 的 MLP；C 只在有真实任务 oracle 后再考虑。

## 4. 需要补的实现点

- 前向缓存：`FeatureTable` 已经缓存了 `layer_inputs` / `layer_pre`，可直接做反向。
- 输出层损失：`Net::readout` 对最后一层用 f32 raw，隐藏层用符号；反向要按同样语义求导。
- 三值激活的 STE：`sign(x)` 的导数取 1（或 `|x| < 1` 的指示），在测试里钉住。
- 梯度累加：按 oracle 样本求和/平均；`|grad|` 排序时对 bias 与 trit 分开归一化。
- 对拍：`analyze` 的 `gain` top-K vs `|grad|` top-K；报告重叠率、命中率、耗时。

## 5. 未证栏

- STE 梯度与离散编辑真实收益的相关性未测。
- 反向传播实现还没落地（本文是设计）。
- 真实大模型上的梯度尺度/数值稳定性未测。
- 端到端 C 需要可微代理，代理与真实 `gain` 的偏差未证。
