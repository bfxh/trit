# 仓库防杂乱模板（排版与理念纪律）

> 病灶定义：仓库的"杂"不是箱子堆得乱，而是——
> ①**换词重复**：同一设计换个词重发（论文、库、项目通病）；
> ②**理念污染**：定位外的功能塞进来，理念互相打架；
> ③**排版失序**：没小标题、没表格、没出处，读者无法复算。
> 本模板 + 概念台账（`src/vocab.rs`）对症。

## 一、目录骨架（一仓一域，超界开新仓）

```text
<仓>/
├── spec/        # 决策与台账：ROADMAP（愿景账本）、ROUNDLOG（逐轮证据）
├── docs/        # 对外解释（面向读者，排版从优）
├── src|crates/  # 代码（一文件一职责；> 2000 行必须拆）
├── tests/       # 行为对拍（每个公共承诺至少一条测试）
├── examples/    # 可复算示例
└── scripts/     # 一次性脚本（不入主逻辑，用完可删）
```

- 新目录/新顶层文件先问一句：**这属于本仓一句话定位吗？**不属于 = 污染，开新仓。
- 临时实验不进仓库：要么转正（有测试、有文档），要么删。

## 二、文档排版规范（排版要好，读者可复算）

1. 每篇：**标题 → 一句话定位 → 分节正文（每节有小标题）→ 结论**；
2. 表格优先于长段落；断言必带出处（测试名 / 论文 / 实测数字）；
3. 代码示例必须可复算（命令给全，数字来自测试输出）；
4. **禁止无定义的新词**：造词先过概念台账（见下）；已有概念禁止再造同义词——
   别名收编进规范名，不立新词；
5. 中文面向（与 ADV 语种账结论一致），术语首次出现给原文。

## 三、理念纪律

- **一仓一句话定位**；定位外的功能 = 理念污染，拒绝或开新仓；
- 库选型三问（借 ADV）：理念契合 > 版本前沿 > 省 token；
- PR 纪律（借 ADV）：一个 PR 一个功能，过程发现的问题另开 PR 引用出处，不搭车；
- **算子库归 trit**（bfxh/trit 的域：三值点积/传播等数值与逻辑算子）——内核只消费
  算子，不自己攒算子库；平台算子同理挂各自域。

## 四、台账流程（新设计的四步）

1. 查台账：对概念的每个已知别名跑 `Vocabulary::explain`——命中 = **挂别名，不立新词**；
2. 登记 → `Duplicate`（属性同构）= **换词不换设计，拒收**，指认出处；
3. 登记 → `Overlap`（部分重叠）= 挂起，人工裁决并引用出处；
4. 登记 → `Accepted` = 入账，规范名 + 别名 + 设计属性一次写全（空属性的条目
   不参与同构判定）。

## 五、最小检查清单（提交前过一遍）

- [ ] 一句话定位还成立吗？
- [ ] 新词查过台账吗？（换词 = 污染）
- [ ] 断言有出处吗？（测试/论文/实测数字）
- [ ] 排版：小标题、表格、可复算示例？
- [ ] 构建产物没进仓库吗？（`harvest` 白名单之外的也不该手塞）
- [ ] 定位外的功能没搭车吗？
