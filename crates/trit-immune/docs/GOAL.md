# 目标：从累积走向收敛

## 病灶（二进制系统的宿命）

| 病 | 机理 |
|----|------|
| 概念账越积越多 | 二值系统里每个新词都能"通过"，同义词各立新词，无人合并 |
| PR 越来越多 | 一个 finding 一个 PR，修症状不修根因，只进不出 |
| 智能体无限修复 | 没有完成的定义——修完一个又冒一个，开放式循环 |

半自动批省事但不行：**没有证据的放行就是污染的入口**。

## 三进制的三个结构性药方

### 1. 0 态驻留（修复从循环变队列）

未决的东西**冻结在 0**，不逼智能体修。`suspects()` 是有限队列、人工裁量，
永远有底。智能体的劳动从"无限循环修复"变成"消费有限队列"。

### 2. 同类项折叠（账本体积由设计空间决定，不由工作量决定）

- 概念台账：**体积上限 = 不同设计的数量**；别名只增折叠率不增体积
  （`vocab::absorption` 度量）；换词不换设计 → 同构检测拒收并指认出处；
- 日志：stamp 即身份，克隆前缀去重；冲突 LWW 归并且历史双留（不靠删除收敛）；
- 隔离子树：未放行内容在导出时剔除——污染不进下游。

### 3. 有界劳动（智能体循环可证明终止）

`Decision::Hold` 必须携带**机器可执行动作**（`Action`）：`RunLayer(n)` /
`AddBaseline(b)` / `HumanReview` / `EnableAutoMerge`。每个动作使单调状态前进一步：

- `RunLayer(i)`：`layers[i]` 从 0 → ±1，每层至多变一次；
- `AddBaseline(b)`：基准集 ⊆ 策略要求的固定集合；
- `HumanReview`：隔离数量有限，复核要么解除要么确证（确证 = 终态 Block）；
- `EnableAutoMerge`：一次性开关。

⇒ 智能体循环的迭代次数 ≤ 层数 + 基准数 + 隔离数 + 1，**有证明的终止**
（测试 `agent_loop_terminates_within_bound` 模拟整条循环并断言步数上界）。

## 质量立场

- 代码质量：分层 CI 永远在动，任何一层 -1 阻断，全 +1 且基准齐才放行；
- 设计质量：机械判据由系统强制（`coupling` 扇入阈值 → `design_smells` 设计层 0 态候选、
  排版与命名由模板与台账约束）——**把噪音降到人眼能看见设计**；
- 审美不自动判：那是人的 0 态主权，系统的职责是让需要人看的决定少而准。

## 度量（只许单向改善）

| 度量 | 含义 | 目标 |
|------|------|------|
| `ImmuneDag::convergence().ratio` | hardened / total——距"全 +1 固定点"的距离 | 单调趋近 1.0；回退必须可解释 |
| `Vocabulary::absorption().ratio` | 别名 / (概念 + 别名)——词折叠成概念的比率 | 越高越好；新词入账必须带来新属性 |
| 智能体循环步数 | 每次 PR 决策的 Hold 次数 | ≤ 层数 + 基准数 + 隔离数 + 1 |
